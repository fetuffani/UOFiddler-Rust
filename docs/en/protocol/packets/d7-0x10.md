# 0xD7 / 0x10 - House: clear
Direction: client -> server. Size: fixed 10 bytes total.
Purpose: erases the design and returns to the empty foundation.

Layout identical to 0x02, with `subcommand = 0x0010`. The server rebuilds the foundation, increments the revision and resends the state.
