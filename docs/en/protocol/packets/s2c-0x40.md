# 0x40 - Update Terrain (God client; UltimaLive)

Direction: server -> client. Size: 201 bytes.

Purpose: UltimaLive: sends the terrain (64 cells) of a map block.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x40 |
| 1 | 4 | u32 | blockNumber | Block number. |
| 5 | 192 | cell[64] | tiles | 64 cells of 3 bytes: `tileId` u16 + `z` i8. |
| 197 | 3 | u8[3] | padding | Zeros. |
| 200 | 1 | u8 | mapId | Map. |
