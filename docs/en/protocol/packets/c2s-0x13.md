# 0x13 - Equip Item Request

Direction: client -> server. Size: 10 bytes (fixed). Available: in game.

Purpose: Equips the item being dragged.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x13 |
| 1 | 4 | u32 | serial | item serial |
| 5 | 1 | u8 | layer | equipment layer |
| 6 | 4 | u32 | mobile | serial of the mobile that will receive the item (0 or invalid = the player itself) |

Notes:

The item must be in hand (previous 0x07 packet). On failure the server returns the item (0x27 Reject Move Item).
