# 0x34 - Get Player Status

Direction: client -> server. Size: 10 bytes (fixed). Available: in game.

Purpose: Queries the status or skills of a mobile.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x34 |
| 1 | 4 | u32 | pattern | 0xEDEDEDED |
| 5 | 1 | u8 | type | 0x04 = status; 0x05 = skills |
| 6 | 4 | u32 | serial | mobile serial |

Notes:

Response: 0x11 Mobile Status for type 4; 0x3A Skills List for type 5. Type 0x00 is sent by the God client.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`MobileQuery`)
- Source-X: `src/network/receive.cpp` (`PacketObjStatusReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_StatusRequest`, `Send_SkillsRequest`)
