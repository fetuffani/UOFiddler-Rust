# 0x70 - Graphical Effect

Direction: server -> client. Size: 28 bytes.

Purpose: Displays a graphical effect (projectile, lightning, fixed effect).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x70 |
| 1 | 1 | u8 | type | 0 = moves from source to destination, 1 = lightning, 2 = fixed at position, 3 = fixed on the source mobile. |
| 2 | 4 | u32 | sourceSerial |  |
| 6 | 4 | u32 | targetSerial |  |
| 10 | 2 | u16 | graphic | ItemID of the effect. |
| 12 | 2 | u16 | srcX |  |
| 14 | 2 | u16 | srcY |  |
| 16 | 1 | i8 | srcZ |  |
| 17 | 2 | u16 | dstX |  |
| 19 | 2 | u16 | dstY |  |
| 21 | 1 | i8 | dstZ |  |
| 22 | 1 | u8 | speed |  |
| 23 | 1 | u8 | duration |  |
| 24 | 2 | u16 | unknown | 0. |
| 26 | 1 | bool | fixedDirection |  |
| 27 | 1 | bool | explode |  |

Notes:

0xC0 (colored effect) has the same beginning, followed by hue and render mode.
