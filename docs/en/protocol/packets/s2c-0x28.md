# 0x28 - Drop Item Failed / Clear Square

Direction: server -> client. Size: 5 bytes.

Purpose: Ends the dragging-item state on the client.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x28 |
| 1 | 4 | u8[4] | payload | Not specified. |

Notes:

The client handles the packet without reading any field (clears the held item state). The content of the 4 bytes is not defined by the implementations consulted.
