# 0x81 - Change Character
Direction: server -> client. Size: variable (id + u16 length + payload; length is the total size of the packet).
Purpose: Lists the account's characters so the player can switch characters.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x81 |
| 1 | 2 | u16 | length | Total size of the packet, including the id and this field |
| 3 | 1 | u8 | count | Number of occupied slots |
| 4 | 1 | u8 | reserved | 0 |
| 5 | 60 x N | entry[] | characters | N = account length (ServUO/ModernUO: `5 + 60*N` bytes in total) |

Notes: Each entry takes 60 bytes: a 30-byte ASCII name padded with 0x00, followed by 30 zeroed bytes (password field, always empty). Free slot = 60 zeroed bytes. ClassicUO does not register a handler for 0x81; Source-X does not send this packet to KR/Enhanced clients.

- ModernUO: `Projects/Server/Network/Packets/OutgoingAccountPackets.cs` (`SendChangeCharacter`)
