# 0xBF / 0x15 - Context menu response
Direction: client -> server. Size: fixed 11 bytes total.
Purpose: reports which context menu entry was chosen.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0015 |
| 5 | 4 | u32 | serial | Menu target |
| 9 | 2 | u16 | index | Index of the chosen entry (the `index` field of 0x14) |

Notes: ServUO discards the response if there is no pending menu for the player or if the player is out of range of the entry.
