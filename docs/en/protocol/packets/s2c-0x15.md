# 0x15 - Follow

Direction: server -> client. Size: 9 bytes.

Purpose: Informs which entity is following another.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x15 |
| 1 | 4 | u32 | follower | Serial of the follower. |
| 5 | 4 | u32 | target | Serial of the followed target. |

Notes:

The client reads both fields and applies no visible effect.
