# 0x04 - GodModeRequest

Direction: client -> server. Size: 2 bytes (fixed). Available: in game (God client only).

Purpose: Requests to enable God mode.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x04 |
| 1 | 1 | u8 | enable | 0 or 1 |

Notes:

ServUO disconnects accounts without staff privileges. Response: 0x2B (2 bytes).

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`GodModeRequest`)
