# 0xBF / 0x25 - Toggle spell/ability icon
Direction: server -> client. Size: fixed 8 bytes total.
Purpose: turns on or off the icon of a special ability/spell.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 8 |
| 3 | 2 | u16 | subcommand | 0x0025 |
| 5 | 2 | u16 | abilityId | Ability/spell id |
| 7 | 1 | u8 | active | 1 = active, 0 = inactive |
