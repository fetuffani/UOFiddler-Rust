# 0xBF / 0x16 - Close interface window
Direction: server -> client. Size: fixed 13 bytes total.
Purpose: closes a client interface window (paperdoll, status, profile, container).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0016 |
| 5 | 4 | u32 | windowType | Table below |
| 9 | 4 | u32 | serial | Serial of the window's owner |

| windowType | Window |
|---|---|
| 1 | Paperdoll |
| 2 | Status bar/window |
| 8 | Character profile |
| 0x0C | Container |
