# 0xD7 / 0x04 - House: commit
Direction: client -> server. Size: fixed 10 bytes total.
Purpose: confirms the design and exits customization mode.

Layout identical to 0x02, with `subcommand = 0x0004`. The server calculates the cost, debits/credits the bank, ends customization (0xBF/0x20 type 5) and resends the final state.

## Example

Player with serial 0x00000001 confirms the design:

```
D7 00 0A 00 00 00 01 00 04 0A
```

| Bytes | Meaning |
|---|---|
| `D7` | id |
| `00 0A` | length = 10 |
| `00 00 00 01` | player serial |
| `00 04` | subcommand = commit |
| `0A` | terminator |

Placing an item (0xD7 / 0x06), graphic 0x0001, x = 2, y = 3, 25 bytes:

```
D7 00 19 00 00 00 01 00 06 00 00 00 00 01 00 00 00 00 02 00 00 00 00 03 0A
```

Each value is `00` + `u32`: `00 00 00 00 01`, `00 00 00 00 02`, `00 00 00 00 03`.
