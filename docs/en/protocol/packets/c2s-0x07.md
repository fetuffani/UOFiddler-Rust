# 0x07 - Pick Up Item

Direction: client -> server. Size: 7 bytes (fixed). Available: in game.

Purpose: Picks up (drags) an item or part of a stack.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x07 |
| 1 | 4 | u32 | serial | item serial |
| 5 | 2 | u16 | amount | quantity to pick up |

Notes:

Response on refusal: 0x27 Reject Move Item.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`LiftReq`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingItemPackets.cs` (`LiftReq`)
- Source-X: `src/network/receive.cpp` (`PacketItemPickupReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_PickUpRequest`)
