# 0xD7 / 0x0C - House: exit designer
Direction: client -> server. Size: fixed 10 bytes total.
Purpose: closes the design window without confirming.

Layout identical to 0x02, with `subcommand = 0x000C`. The server ends customization (0xBF/0x20 type 5), resends the visible state of the house and moves anyone inside outside.
