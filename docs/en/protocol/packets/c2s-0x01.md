# 0x01 - Disconnect / Logout

Direction: client -> server. Size: 5 bytes (fixed). Available: before login and in game.

Purpose: Notifies that the connection is being closed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x01 |
| 1 | 4 | i32 | marker | -1 (0xFFFFFFFF) |

Notes:

The server reads the value and ignores it.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`Disconnect`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingPlayerPackets.cs` (`Disconnect`)
