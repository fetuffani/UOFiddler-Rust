# 0x47 - NewTerrain

Direction: client -> server. Size: 11 bytes (fixed). Available: in game (God client only).

Purpose: Edits terrain (God client).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x47 |
| 1 | 2 | i16 | x | X position |
| 3 | 2 | i16 | y | Y position |
| 5 | 2 | u16 | tileId | tile id |
| 7 | 2 | i16 | width | width |
| 9 | 2 | i16 | height | height |

Notes:

ServUO only logs the content.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`NewTerrain`)
