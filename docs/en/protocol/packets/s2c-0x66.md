# 0x66 - Book Pages

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Sends the text of one or more pages of a book.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x66 |
| 1 | 2 | u16 | length | Total size. |
| 3 | 4 | u32 | serial | Book. |
| 7 | 2 | u16 | pageCount | Number of pages in the packet. |
| 9+ | n | page | pages | Repeated `pageCount` times (format below). |

**Page**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 2 | u16 | pageNumber | Base 1. |
| +2 | 2 | u16 | lineCount | Number of lines. |
| +4 | n | UTF-8\0[] | lines | `lineCount` strings terminated by 0x00. |

Notes:

Lines: text terminated by 0x00 (UTF-8 in newer books; ASCII in older books). ServUO sends `pageCount` = total number of pages when opening the book, or 1 when responding to a page request.
