# 0xBF / 0x18 - Enable map patches
Direction: server -> client. Size: variable (`9 + 8 * mapCount`).
Purpose: informs the number of blocks in each map's diff files.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | Total size (41 for 4 maps) |
| 3 | 2 | u16 | subcommand | 0x0018 |
| 5 | 4 | u32 | mapCount | Number of maps described |
| 9 | 8 | pair[mapCount] | patches | Per map: `u32 staticBlocks` + `u32 landBlocks` |

Notes:
- ServUO, ModernUO and ClassicUO use the order "statics, then terrain". Source-X writes the length of the terrain diff file first and the statics one afterward (reverse order); this is an unresolved divergence between implementations.
- Each count is the size of the diff index file (`*difl`) divided by 4.
