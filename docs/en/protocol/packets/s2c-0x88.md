# 0x88 - Open Paperdoll
Direction: server -> client. Size: 66 bytes.
Purpose: Opens the paperdoll window of a mobile.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x88 |
| 1 | 4 | u32 | serial | Mobile serial |
| 5 | 60 | ascii[60] | text | Displayed title (name and titles), ASCII padded with 0x00 |
| 65 | 1 | u8 | flags | Bits below |

Notes: Bits of `flags`:

| Bit | Meaning |
|---|---|
| 0x01 | Mobile in war mode |
| 0x02 | The player can lift (drag) items from the paperdoll |
