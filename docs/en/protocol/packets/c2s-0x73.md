# 0x73 - Ping

Direction: client -> server. Size: 2 bytes (fixed). Available: before login and in game.

Purpose: Measures latency.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x73 |
| 1 | 1 | u8 | value | arbitrary counter/value |

Notes:

Response: 0x73 packet (2 bytes) with the same value.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`PingReq`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingPlayerPackets.cs` (`PingReq`)
- Source-X: `src/network/receive.cpp` (`PacketPingReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_Ping`)
