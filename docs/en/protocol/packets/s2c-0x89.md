# 0x89 - Corpse Clothing
Direction: server -> client. Size: variable (id + u16 length + payload; length is the total size of the packet).
Purpose: Lists the equipped items on a corpse.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x89 |
| 1 | 2 | u16 | length | Total size of the packet, including the id and this field |
| 3 | 4 | u32 | serial | Corpse serial |
| 7 | 5 x N | entry[] | items | Entries: u8 layer+1, u32 item serial |
| end | 1 | u8 | terminator | 0x00 |

Notes: Entry: `u8 layerPlus1` (ServUO and ClassicUO: the value sent is `layer + 1`; the client subtracts 1) followed by `u32 serial`. Source-X writes the layer value without adding 1. The list ends with a 0x00 byte. ClassicUO ignores the entry whose layer (after subtracting 1) is Backpack, and ignores the packet if the object is not a corpse (graphic 0x2006). ServUO also sends hair and beard with fictitious serials.
