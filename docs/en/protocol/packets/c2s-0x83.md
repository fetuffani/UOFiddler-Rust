# 0x83 - DeleteCharacter

Direction: client -> server. Size: 39 bytes (fixed). Available: before login.

Purpose: Deletes a character from the account.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x83 |
| 1 | 30 | char[30] | password | confirmation password (the reference client sends zeros) |
| 31 | 4 | u32 | slot | character slot |
| 35 | 4 | u32 | clientIp | client IPv4 |

Notes:

Response: updated character list (0xA9) or an error message, depending on the server.
