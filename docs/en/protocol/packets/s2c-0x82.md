# 0x82 - Login Denied
Direction: server -> client. Size: 2 bytes.
Purpose: Rejects the account login with a reason code.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x82 |
| 1 | 1 | u8 | reason | Reason code |

Notes: Values defined on the server (`ALRReason`):

| Value | Name |
|---|---|
| 0x00 | Invalid |
| 0x01 | InUse (account in use) |
| 0x02 | Blocked |
| 0x03 | BadPass |
| 0xFE | Idle |
| 0xFF | BadComm |

ClassicUO uses the same handler for 0x82, 0x85 and 0x53 and converts the code into an error message; the exact texts depend on the client.
