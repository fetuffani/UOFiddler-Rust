# 0x72 - War Mode

Direction: server -> client. Size: 5 bytes.

Purpose: Reports the war mode state.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x72 |
| 1 | 1 | bool | warMode | 1 = war. |
| 2 | 1 | u8 | fixed1 | 0x00. |
| 3 | 1 | u8 | fixed2 | 0x32. |
| 4 | 1 | u8 | fixed3 | 0x00. |
