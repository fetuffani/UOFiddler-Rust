# 0x00 - Create Character

Direction: client -> server. Size: 104 bytes (fixed). Available: before login (character selection screen).

Purpose: Requests the creation of a character in the classic layout (3 skills).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x00 |
| 1 | 4 | u32 | padding | 0xEDEDEDED |
| 5 | 4 | u32 | padding | 0xFFFFFFFF |
| 9 | 1 | u8 | reserved | 0x00 |
| 10 | 30 | char[30] | name | ASCII, padded with NUL |
| 40 | 2 | u8[2] | reserved | zeros |
| 42 | 4 | u32 | flags | client protocol flags (the server stores them as ClientFlags) |
| 46 | 4 | u32 | reserved | the reference client sends 0x00000001 |
| 50 | 4 | u32 | reserved | the reference client sends 0x00000000 |
| 54 | 1 | u8 | profession | 0 = custom; other values = chosen profession |
| 55 | 15 | u8[15] | reserved | zeros |
| 70 | 1 | u8 | genderRace | see table below |
| 71 | 1 | u8 | str | initial strength |
| 72 | 1 | u8 | dex | initial dexterity |
| 73 | 1 | u8 | int | initial intelligence |
| 74 | 1 | u8 | skill1 | index of skill 1 |
| 75 | 1 | u8 | skill1Value | value of skill 1 |
| 76 | 1 | u8 | skill2 | index of skill 2 |
| 77 | 1 | u8 | skill2Value | value |
| 78 | 1 | u8 | skill3 | index of skill 3 |
| 79 | 1 | u8 | skill3Value | value |
| 80 | 2 | u16 | skinHue | skin color |
| 82 | 2 | u16 | hairId | hair style (0 = none) |
| 84 | 2 | u16 | hairHue | hair color |
| 86 | 2 | u16 | facialHairId | facial hair style (0 = none) |
| 88 | 2 | u16 | facialHairHue | facial hair color |
| 90 | 1 | u8 | reserved | zero (high byte of the city field when read as u16) |
| 91 | 1 | u8 | cityIndex | index of the starting city |
| 92 | 4 | u32 | slot | character slot in the account |
| 96 | 4 | u32 | clientIp | client IPv4 |
| 100 | 2 | u16 | shirtHue | shirt color |
| 102 | 2 | u16 | pantsHue | pants color |

Notes:

`genderRace`: bit 0 = sex (0 male, 1 female). Value / 2 = race.

| Client | Values |
|---|---|
| before 7.0.0.0 | 0/1 human M/F; 2/3 elf M/F |
| 7.0.0.0 or later | 2/3 human M/F; 4/5 elf M/F; 6/7 gargoyle M/F |

In clients before 4.0.11d the field carries only the sex (0 or 1).

Clients 7.0.16.0 or later send the 106-byte layout of packet 0xF8 (four skills). The size table lists 104 bytes for id 0x00.
The reference client computes the packet size from the id 0x00 table; for clients 7.0.18.0 or later it is 106.

Response: on success the server starts the world entry sequence (0x1B Login Confirm and other state packets). On refusal, it sends an error message (for example 0x82 Login Denied).
