# 0x73 - Ping

Direction: server -> client. Size: 2 bytes.

Purpose: Ping response.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x73 |
| 1 | 1 | u8 | value | Value received in the client's ping, returned unchanged. |
