# 0x31 - Attack Ended / Pet Window

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: In the ServUO implementation, lists the player's followers (pet window).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x31 |
| 1 | 2 | u16 | length | Total size (8 + 5 * count). |
| 3 | 4 | u32 | ownerSerial | Owner. |
| 7 | 1 | u8 | count | Number of followers. |
| 8+5n | 4 | u32 | followerSerial | Follower serial. |
| 12+5n | 1 | u8 | flag | 0x01. |

Notes:

- Discrepancy: packets.md names 0x31 as `Attack Ended` with variable size, while the ClassicUO length table indicates 1 byte and ServUO emits the layout above. The actual meaning of the id is not confirmed.
- Entries: `count` repetitions of 5 bytes.
