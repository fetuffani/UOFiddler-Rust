# 0xBF / 0x07 - Quest arrow click
Direction: client -> server. Size: fixed 6 bytes total.
Purpose: the player clicked the quest arrow (pointer).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 6 |
| 3 | 2 | u16 | subcommand | 0x0007 |
| 5 | 1 | u8 | rightClick | 1 = right button, 0 = left |
