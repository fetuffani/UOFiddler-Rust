# 0x91 - Game Server Login

Direction: client -> server. Size: 65 bytes (fixed). Available: before login (connection to the game server).

Purpose: Authenticates on the game server using the key received in 0x8C.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x91 |
| 1 | 4 | u32 | authId | authentication key received in 0x8C Connect To Game Server |
| 5 | 30 | char[30] | account | account name |
| 35 | 30 | char[30] | password | password |

Notes:

Response: 0xB9 (features enabled) and character list 0xA9. It is the first packet on the game server connection after the seed; a second 0x91 on the same connection is rejected.
