# 0xBF / 0x20 - Start/end house customization
Direction: server -> client. Size: fixed 17 bytes total.
Purpose: enters or leaves house design mode.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 17 |
| 3 | 2 | u16 | subcommand | 0x0020 |
| 5 | 4 | u32 | serial | House |
| 9 | 1 | u8 | type | 4 = start, 5 = end (1, 2 and 3 exist in the client as update/remove/move, but have no action) |
| 10 | 2 | u16 | graphic | 0x0000 |
| 12 | 2 | u16 | x | 0xFFFF |
| 14 | 2 | u16 | y | 0xFFFF |
| 16 | 1 | i8 | z | 0xFF |
