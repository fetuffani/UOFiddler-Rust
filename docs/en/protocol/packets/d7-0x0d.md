# 0xD7 / 0x0D - House: place staircase (multi)
Direction: client -> server. Size: fixed 25 bytes total.
Purpose: adds a staircase (multi-tile piece).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 25 |
| 3 | 4 | u32 | playerSerial | Player |
| 7 | 2 | u16 | subcommand | 0x000D |
| 9 | 5 | enc32 | multiId | Staircase multi id (Source-X adds `ITEMID_MULTI` to the value read) |
| 14 | 5 | enc32 | x | X offset |
| 19 | 5 | enc32 | y | Y offset |
| 24 | 1 | u8 | terminator | 0x0A |

Notes: ServUO validates the id as a staircase multi; if invalid, it resends the state.
