# 0xBF / 0x31 - Bandage timer
Direction: server -> client. Size: fixed 15 bytes total.
Purpose: displays the countdown of bandage use.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 15 |
| 3 | 2 | u16 | subcommand | 0x0031 |
| 5 | 2 | u16 | command | 1 |
| 7 | 4 | u32 | icon | 0x00000E21 (bandage graphic) |
| 11 | 4 | u32 | duration | Duration |

Notes: appears only in ServUO (`BandageTimerPacket`). The unit of `duration` is not specified in the code.
