# 0xBF / 0x05 - Screen size
Direction: client -> server. Size: fixed 13 bytes total.
Purpose: reports the resolution of the game window.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0005 |
| 5 | 4 | u32 | width | Width in pixels |
| 9 | 4 | u32 | height | Height in pixels |

Notes: Source-X treats height 0 with width > 0 as "height omitted" and assumes 600 (800), 768 (1024), 864 (1152), 720 (1280) or 480 (others). ServUO/ModernUO read and discard it.
