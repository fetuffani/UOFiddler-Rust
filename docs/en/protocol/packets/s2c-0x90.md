# 0x90 - Map Message
Direction: server -> client. Size: 19 bytes.
Purpose: Opens a map gump (map item) with the map bounds.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x90 |
| 1 | 4 | u32 | serial | Map item serial |
| 5 | 2 | u16 | gumpId | Gump id (0x139D) |
| 7 | 2 | u16 | startX | Upper-left corner, X |
| 9 | 2 | u16 | startY | Upper-left corner, Y |
| 11 | 2 | u16 | endX | Lower-right corner, X |
| 13 | 2 | u16 | endY | Lower-right corner, Y |
| 15 | 2 | u16 | width | Gump width in pixels |
| 17 | 2 | u16 | height | Gump height in pixels |

Notes: The variant with the facet id is 0xF5 (see s2c-0xf5).
