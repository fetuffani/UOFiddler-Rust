# 0xBF / 0x04 - Close generic gump
Direction: server -> client. Size: fixed 13 bytes total.
Purpose: closes a gump opened by the server, optionally simulating a click on a button.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0004 |
| 5 | 4 | u32 | gumpTypeId | Type (TypeID) of the gump to close |
| 9 | 4 | u32 | buttonId | Button to "press" when closing; 0 = just close |

Notes: with `buttonId != 0` the client performs the button click and closes the gump; with 0 it only saves/removes the position and closes.
