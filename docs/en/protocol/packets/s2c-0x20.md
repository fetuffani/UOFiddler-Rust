# 0x20 - Draw Game Player (own position/direction)

Direction: server -> client. Size: 19 bytes.

Purpose: Updates the body, color, flags, position and direction of the player's character.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x20 |
| 1 | 4 | u32 | serial | Player. |
| 5 | 2 | u16 | body | Body. |
| 7 | 1 | u8 | bodyOffset | 0 (body increment). |
| 8 | 2 | u16 | hue | Color. |
| 10 | 1 | u8 | flags | See table. |
| 11 | 2 | u16 | x | X. |
| 13 | 2 | u16 | y | Y. |
| 15 | 2 | u16 | serverId | 0 in ServUO/ModernUO. |
| 17 | 1 | u8 | direction | Direction. |
| 18 | 1 | i8 | z | Z. |

Notes:

Mobile flags (`flags`):

| Bit | Meaning |
|---|---|
| 0x01 | Frozen/paralyzed |
| 0x02 | Female |
| 0x04 | Poisoned (before client 7.0.0.0) or flying (after) |
| 0x08 | Yellow health bar (blessed/invulnerable) |
| 0x10 | Ignores mobiles |
| 0x20 | Movable |
| 0x40 | War mode |
| 0x80 | Hidden |

Servers before client 7.0.0.0 send bit 0x04 as poison (`GetOldPacketFlags`).
