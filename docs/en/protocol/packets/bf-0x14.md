# 0xBF / 0x14 - Display context menu
Direction: server -> client. Size: variable (`12 + sum of the entries`).
Purpose: sends the entries of the context menu.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | Total size |
| 3 | 2 | u16 | subcommand | 0x0014 |
| 5 | 2 | u16 | mode | 1 = entries in the old format; 2 (or higher) = new format |
| 7 | 4 | u32 | serial | Menu target |
| 11 | 1 | u8 | count | Number of entries |
| 12 | ... | entry[count] | entries | See below |

Entry in the new format (`mode >= 2`), 8 bytes:

| Field | Type | Description |
|---|---|---|
| cliloc | u32 | Full cliloc of the text (ServUO adds 3000000 if the number is <= 65535 in the "Old" format with color) |
| index | u16 | Index returned in 0x15 |
| flags | u16 | Flags table |

Entry in the old format (`mode = 1`), 6 bytes plus 2 optional:

| Field | Type | Description |
|---|---|---|
| index | u16 | Index returned in 0x15 |
| cliloc - 3000000 | u16 | Cliloc is 3000000 + value |
| flags | u16 | Flags table |
| color | u16 | Present only if `flags & 0x20` (text color) |

Flags (`CMEFlags`):

| Value | Name | Meaning |
|---|---|---|
| 0x0000 | None | Enabled |
| 0x0001 | Disabled | Entry disabled (the client draws it in gray) |
| 0x0002 | Arrow | Entry with an arrow (submenu) |
| 0x0004 | Highlighted | Highlighted |
| 0x0020 | Colored | For the old format, a `u16 color` follows the flags |

Notes:
- In ModernUO, `mode = 2` is only used for the New Haven/EC client with an entry that requires the new format; otherwise it sends `mode = 1`.
- In the old format ClassicUO also consumes 2 extra bytes when the flags `0x84` or `0x40` are set; the servers consulted do not emit these flags.
- The index returned in 0x15 is the position of the entry in the list (0 to count-1).
