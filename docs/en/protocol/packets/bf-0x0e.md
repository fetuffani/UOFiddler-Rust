# 0xBF / 0x0E - Animation (macro)
Direction: client -> server. Size: fixed 9 bytes total.
Purpose: asks the character to perform an animation (emote macros).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 9 |
| 3 | 2 | u16 | subcommand | 0x000E |
| 5 | 4 | u32 | action | Animation id |

Notes: the server only accepts these values: 6, 21, 32, 33, 100 to 121, 123 to 128 (ServUO, ModernUO, Source-X). It only applies to a human character that is alive and dismounted.
