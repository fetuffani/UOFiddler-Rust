# 0x16 - Healthbar update (SA/EC)

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Updates the color of the health bar (Enhanced Client / Stygian Abyss format).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x16 |
| 1 | 2 | u16 | length | Total size (7 + 3 * count; 12 with count = 1). |
| 3 | 4 | u32 | serial | Mobile. |
| 7 | 2 | u16 | count | Number of entries. |
| 9+3n | 2 | u16 | type | Bar type: 1 = poison, 2 = yellow bar (invulnerable/blessed), 3 = unknown. |
| 11+3n | 1 | u8 | enabled | 0 = turns off; for poison ServUO sends level + 1; for yellow it sends 1 or 0. |

Notes:

- Each entry is 3 bytes (`type` u16 + `enabled` u8) and repeats `count` times.
- ClassicUO ignores this id when the client version is earlier than 5.0.0a; it uses the same handling as 0x17.

## Implementation reference

- ServUO: `Server/Network/Packets.cs`: `HealthbarPoisonEC`, `HealthbarYellowEC`
- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketHealthBarUpdateNew`
