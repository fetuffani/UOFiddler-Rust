# 0x08 - Drop Item

Direction: client -> server. Size: 14 bytes (clients before 6.0.1.7) | 15 bytes (6.0.1.7 or later). Available: in game.

Purpose: Drops the picked-up item on the ground, into a container, or onto a mobile.

**14-byte layout**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x08 |
| 1 | 4 | u32 | serial | item serial |
| 5 | 2 | i16 | x | X position (or coordinate inside the container) |
| 7 | 2 | i16 | y | Y position |
| 9 | 1 | i8 | z | Z position |
| 10 | 4 | u32 | container | destination serial |

**15-byte layout (6.0.1.7 or later)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x08 |
| 1 | 4 | u32 | serial | item serial |
| 5 | 2 | i16 | x | X position |
| 7 | 2 | i16 | y | Y position |
| 9 | 1 | i8 | z | Z position |
| 10 | 1 | u8 | gridIndex | cell index in the grid-based container; 0xFF = first free cell |
| 11 | 4 | u32 | container | destination serial |

Notes:

A destination that is neither an item nor a mobile serial (for example 0xFFFFFFFF) means dropping on the ground at (x, y, z). A mobile destination means handing the item to the mobile. An item destination means placing it in the container; on multis with relative drop, x and y are relative to the multi.
Source-X expects 15 bytes for clients >= 6.0.1.7, KR and Enhanced. ModernUO only reads the grid byte when the client uses grid-based containers.
