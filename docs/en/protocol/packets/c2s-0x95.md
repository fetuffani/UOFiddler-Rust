# 0x95 - HuePickerResponse

Direction: client -> server. Size: 9 bytes (fixed). Available: in game.

Purpose: Response to the color picker (server 0x95).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x95 |
| 1 | 4 | u32 | serial | serial of the picker/object |
| 5 | 2 | u16 | itemId | the reference client sends 0 |
| 7 | 2 | u16 | hue | chosen color (14 bits used, mask 0x3FFF) |
