# 0x77 - Update Mobile (another mobile's move/animation)

Direction: server -> client. Size: 17 bytes.

Purpose: Updates the position, direction, color and flags of another mobile.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x77 |
| 1 | 4 | u32 | serial |  |
| 5 | 2 | u16 | body |  |
| 7 | 2 | u16 | x |  |
| 9 | 2 | u16 | y |  |
| 11 | 1 | i8 | z |  |
| 12 | 1 | u8 | direction |  |
| 13 | 2 | u16 | hue |  |
| 14 | 1 | u8 | flags | See table. |
| 15 | 1 | u8 | notoriety | Notoriety. |

Notes:

Mobile flags (`flags`):

| Bit | Meaning |
|---|---|
| 0x01 | Frozen/paralyzed |
| 0x02 | Female |
| 0x04 | Poisoned (before client 7.0.0.0) or flying (after) |
| 0x08 | Yellow healthbar |
| 0x10 | Ignores mobiles |
| 0x40 | War mode |
| 0x80 | Hidden |

Notoriety: 1 innocent, 2 ally, 3 gray, 4 criminal, 5 enemy, 6 murderer, 7 invulnerable.
For the player's own character the client only updates flags, body, color and notoriety.
