# 0xBF / 0x01 - Fastwalk: initialize key stack
Direction: server -> client. Size: fixed 29 bytes total.
Purpose: fills the six keys of the fast walk prevention stack.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 29 |
| 3 | 2 | u16 | subcommand | 0x0001 |
| 5 | 24 | u32[6] | keys | Six keys; ServUO sends all of them with value 0 |

Notes: the client stores the six keys and consumes them on each step (see 0x02).
