# 0x05 - Attack Request

Direction: client -> server. Size: 5 bytes (fixed). Available: in game.

Purpose: Requests to attack a mobile.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x05 |
| 1 | 4 | u32 | serial | target serial |
