# 0x86 - Character List Update
Direction: server -> client. Size: variable (id + u16 length + payload; length is the total size of the packet).
Purpose: Resends the account's character list after a character is created or deleted.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x86 |
| 1 | 2 | u16 | length | Total size of the packet, including the id and this field |
| 3 | 1 | u8 | count | Number of slots sent |
| 4 | 60 x count | entry[] | characters | See notes |

Notes: Each entry takes 60 bytes: a 30-byte ASCII name padded with 0x00, followed by 30 zeroed bytes (password field, always empty). Free slot = 60 zeroed bytes. ServUO/ModernUO send `count = max(highest occupied slot + 1, account limit, 5)`; the total size is `4 + 60*count`.
