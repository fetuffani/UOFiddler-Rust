# 0x99 - Multi Placement
Direction: server -> client. Size: 30 bytes (HS clients) | 26 bytes (earlier format).
Purpose: Activates a target cursor that shows a multi (house, boat) for placement.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x99 |
| 1 | 1 | u8 | allowGround | 1 if the ground can be targeted |
| 2 | 4 | u32 | targetId | Cursor id, returned in the 0x6C response |
| 6 | 1 | u8 | flags | Target flags |
| 7 | 11 | u8[11] | reserved | Zeros |
| 18 | 2 | u16 | multiId | Multi id (index in multi.mul) |
| 20 | 2 | u16 | offsetX | Cursor X offset |
| 22 | 2 | u16 | offsetY | Y offset |
| 24 | 2 | u16 | offsetZ | Z offset |
| 26 | 2 | u16 | hue | Preview hue (read by ClassicUO; 30-byte variant) |
| 28 | 2 | u8[2] | reserved2 | Zeros (ServUO); Not specified |

Notes: The old 26-byte variant ends at `offsetZ` (offset 24..25). In the 30-byte sizes the last 4 bytes hold the hue and 2 padding bytes.
