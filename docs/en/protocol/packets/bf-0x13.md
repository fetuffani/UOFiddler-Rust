# 0xBF / 0x13 - Request context menu
Direction: client -> server. Size: fixed 9 bytes total.
Purpose: requests the context menu (popup) of an object.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 9 |
| 3 | 2 | u16 | subcommand | 0x0013 |
| 5 | 4 | u32 | serial | Menu target |

Notes: the server's response is 0x14.
