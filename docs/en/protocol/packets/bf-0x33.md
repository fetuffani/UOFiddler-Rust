# 0xBF / 0x33 - Move boat with the mouse
Direction: client -> server. Size: fixed 12 bytes total.
Purpose: controls boat movement with the mouse (HS 7.0.8f or later clients).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 12 |
| 3 | 2 | u16 | subcommand | 0x0033 |
| 5 | 4 | u32 | serial | Player serial |
| 9 | 1 | u8 | facing | Bow direction |
| 10 | 1 | u8 | moving | Movement direction (the client repeats the same direction) |
| 11 | 1 | u8 | speed | 0 = stop, 1 = one tile, 2 = normal movement (Source-X) |
