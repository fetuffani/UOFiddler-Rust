# 0x98 - MobileNameRequest

Direction: client -> server. Size: variable (id + u16 length + payload). Available: in game.

Purpose: Requests the name of one or more mobiles.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x98 |
| 1 | 2 | u16 | length | 3 + 4 x n |
| 3 | 4 | u32 | serial | serial of the mobile (repeated n times) |

Notes:

Source-X processes all serials in the list; ServUO reads only the first one. Response: 0x98 Mobile Name.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`MobileNameRequest`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingMobilePackets.cs` (`MobileNameRequest`)
- Source-X: `src/network/receive.cpp` (`PacketAllNamesReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_NameRequest`)
