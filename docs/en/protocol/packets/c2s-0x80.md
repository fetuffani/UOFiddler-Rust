# 0x80 - Login Request

Direction: client -> server. Size: 62 bytes (fixed). Available: before login.

Purpose: Authenticates the account on the login server.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x80 |
| 1 | 30 | char[30] | account | account name, ASCII with NUL |
| 31 | 30 | char[30] | password | password, ASCII with NUL |
| 61 | 1 | u8 | nextLoginKey | value of NextLoginKey from uo.cfg; the reference client sends 0xFF |

Notes:

Response: 0xA8 Game Server List on success; 0x82 Login Denied (1-byte reason) on failure.
