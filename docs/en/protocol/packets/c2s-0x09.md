# 0x09 - Single Click

Direction: client -> server. Size: 5 bytes (fixed). Available: in game.

Purpose: Requests the name/label of an object (single click).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x09 |
| 1 | 4 | u32 | serial | object serial |

Notes:

Response: label text (speech of type Label) or properties.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`LookReq`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingEntityPackets.cs` (`LookReq`)
- Source-X: `src/network/receive.cpp` (`PacketSingleClick`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_ClickRequest`)
