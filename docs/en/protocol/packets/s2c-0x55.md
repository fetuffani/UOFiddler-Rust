# 0x55 - Login Complete

Direction: server -> client. Size: 1 byte.

Purpose: Indicates that world loading has finished.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x55 |

Notes:

No fields. The client starts the game scene on receipt.
