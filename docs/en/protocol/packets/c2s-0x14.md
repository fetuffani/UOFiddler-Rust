# 0x14 - ChangeZ

Direction: client -> server. Size: 6 bytes (fixed). Available: in game (God client only).

Purpose: Changes the Z coordinate (God client).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x14 |
| 1 | 2 | i16 | x | X position |
| 3 | 2 | i16 | y | Y position |
| 5 | 1 | i8 | z | new Z |

Notes:

ServUO only logs the content.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`ChangeZ`)
