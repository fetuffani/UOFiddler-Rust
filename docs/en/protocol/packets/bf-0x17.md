# 0xBF / 0x17 - Help topic (Codex of Wisdom)
Direction: server -> client. Size: fixed 11 bytes total.
Purpose: opens/activates a Codex of Wisdom topic.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0017 |
| 5 | 1 | u8 | command | 1 |
| 6 | 4 | u32 | topicId | Topic id |
| 10 | 1 | u8 | display | 1 = open/force display, 0 = mark only |
