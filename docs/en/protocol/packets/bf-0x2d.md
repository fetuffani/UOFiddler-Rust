# 0xBF / 0x2D - Spell with target
Direction: client -> server. Size: fixed 11 bytes total.
Purpose: casts a spell directly on a target (macro).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x002D |
| 5 | 2 | u16 | spellId | Spell number + 1 |
| 7 | 4 | u32 | target | Target serial |
