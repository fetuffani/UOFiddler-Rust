# 0x21 - Move Reject

Direction: server -> client. Size: 8 bytes.

Purpose: Rejects a step and repositions the player.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x21 |
| 1 | 1 | u8 | sequence | Sequence number of the rejected step. |
| 2 | 2 | u16 | x | Correct X. |
| 4 | 2 | u16 | y | Correct Y. |
| 6 | 1 | u8 | direction | Direction (the client uses the low 3 bits). |
| 7 | 1 | i8 | z | Correct Z. |
