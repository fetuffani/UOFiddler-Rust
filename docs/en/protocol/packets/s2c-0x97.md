# 0x97 - Move Player
Direction: server -> client. Size: 2 bytes.
Purpose: Makes the client walk one tile in the indicated direction, without sending a movement request.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x97 |
| 1 | 1 | u8 | direction | Direction |

Notes: Bits: `direction & 0x07` = direction (0 North, 1 Northeast, 2 East, 3 Southeast, 4 South, 5 Southwest, 6 West, 7 Northwest); bit 0x80 = running (per the client's handling).
