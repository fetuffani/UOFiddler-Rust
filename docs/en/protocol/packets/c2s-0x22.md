# 0x22 - Resynchronize

Direction: client -> server. Size: 3 bytes (fixed). Available: in game.

Purpose: Asks the server to resend the character and world state.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x22 |
| 1 | 2 | u8[2] | reserved | Not specified; the server does not read it |

Notes:

Response: player update (0x20 or equivalent), 0x78 Mobile Incoming, and resend of nearby objects. The server resets the movement sequence (the next 0x02 uses sequence 0).
