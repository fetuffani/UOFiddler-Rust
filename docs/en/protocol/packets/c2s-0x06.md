# 0x06 - Double Click

Direction: client -> server. Size: 5 bytes (fixed). Available: in game.

Purpose: Uses an object (double click) or opens the paperdoll of a mobile.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x06 |
| 1 | 4 | u32 | serial | object serial; bit 31 = flag |

Notes:

With bit 31 (0x80000000) set: ServUO treats it as a request for the character's own paperdoll; Source-X interprets the bit as a macro/feature flag and uses the remaining 31 bits as the serial.
Typical response: opening a container, paperdoll (0x88), or executing the use, depending on the object.
