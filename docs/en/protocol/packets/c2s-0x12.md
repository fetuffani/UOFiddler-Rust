# 0x12 - Use Skill / Cast / Action

Direction: client -> server. Size: variable (id + u16 length + payload). Available: in game.

Purpose: Text command: skill use, spell, macro, and client actions.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x12 |
| 1 | 2 | u16 | length | total packet size |
| 3 | 1 | u8 | type | command type (table below) |
| 4 | n | char[] | argument | NUL-terminated ASCII (n = length - 4) |

Notes:

| type | Command | Argument |
|---|---|---|
| 0x24 | use skill | "index 0" (skill index, space, zero) |
| 0x27 | cast spell from book | "spellId bookSerial" |
| 0x2F | use old scroll (auto-target) | "serial", "target serial" or "serial x y z" |
| 0x43 | open spellbook | book type |
| 0x56 | cast spell by macro | spell number (1-based) |
| 0x58 | open door (macro) | empty |
| 0xC7 | animation/emote | action name, for example "bow" or "salute" |
| 0xF4 | invoke virtue (macro) | virtue number (1-based) |

For types 0x27 and 0x56 ServUO subtracts 1 from the received number. Clients 6.0.14.2 or later send spell casting via 0xBF (see formats-extended-subcommands.md). Source-X limits the size to 300 + 4 bytes.
