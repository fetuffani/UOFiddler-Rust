# 0xBF / 0x22 - Damage (old format)
Direction: server -> client. Size: fixed 11 bytes total.
Purpose: shows the damage number over a mobile (replaced by packet 0x0B in newer clients).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0022 |
| 5 | 1 | u8 | command | 1 |
| 6 | 4 | u32 | serial | Mobile that took the damage |
| 10 | 1 | u8 | damage | Value (capped at 255) |
