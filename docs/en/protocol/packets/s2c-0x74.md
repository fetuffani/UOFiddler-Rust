# 0x74 - Open Buy Window (vendor list)

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Sends the prices and names of the items a vendor has for sale.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x74 |
| 1 | 2 | u16 | length | Total size (8 + sum of the entries). |
| 3 | 4 | u32 | containerSerial | The vendor's ShopBuy container, or 0xFFFFFFFF. |
| 7 | 1 | u8 | count | Number of entries. |
| 8 | n | entry[] | items | `count` entries (format below). |

**Entry**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 4 | u32 | price | Price. |
| +4 | 1 | u8 | nameLength | Includes the 0x00 terminator. |
| +5 | n | ASCII\0 | name | Name terminated by 0x00. |

Notes:

- Entry size = 6 + len(name without terminator).
- The name can be ASCII text or the number of a cliloc as text; an empty name uses the item's name.
- The entries follow the order of the container items sent earlier by 0x3C.
