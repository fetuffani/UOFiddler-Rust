# 0x23 - Dragging Item (animation)

Direction: server -> client. Size: 26 bytes.

Purpose: Animates an item being moved from a source to a destination.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x23 |
| 1 | 2 | u16 | graphic | ItemID. |
| 3 | 1 | u8 | graphicOffset | 0; added to graphic by the client. |
| 4 | 2 | u16 | hue | Color. |
| 6 | 2 | u16 | amount | Quantity. |
| 8 | 4 | u32 | srcSerial | Source. |
| 12 | 2 | u16 | srcX |  |
| 14 | 2 | u16 | srcY |  |
| 16 | 1 | i8 | srcZ |  |
| 17 | 4 | u32 | dstSerial | Destination. |
| 21 | 2 | u16 | dstX |  |
| 23 | 2 | u16 | dstY |  |
| 25 | 1 | i8 | dstZ |  |

Notes:

If the source/destination is a known mobile, the client uses its current position instead of the X/Y/Z fields.

## Implementation reference

- ServUO: `Server/Network/Packets.cs`: `DragEffect`
- ModernUO: `Projects/Server/Network/Packets/OutgoingPlayerPackets.cs` (`CreateDragEffect`)
- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketDragAnimation`
