# 0xD7 / 0x12 - House: change floor
Direction: client -> server. Size: fixed 15 bytes total.
Purpose: changes the editing floor.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 15 |
| 3 | 4 | u32 | playerSerial | Player |
| 7 | 2 | u16 | subcommand | 0x0012 |
| 9 | 5 | enc32 | level | Target floor (1 to MaxLevels) |
| 14 | 1 | u8 | terminator | 0x0A |

Notes: out-of-range values become 1 in ServUO; the server teleports the player to the new floor.
