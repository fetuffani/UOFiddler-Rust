# 0x84 - Change Password

Direction: client -> server. Size: 69 bytes (fixed). Available: before login.

Purpose: Changes the account password.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x84 |
| 1 | 30 | char[30] | currentPassword | current password, ASCII |
| 31 | 30 | char[30] | newPassword | new password, ASCII |
| 61 | 4 | u32 | unknown | Not specified |
| 65 | 4 | u32 | localIp | client's local IPv4 |

Notes:

No reference server handles this id; the layout comes from the client's packet table.

- Packet table: `docs/en/protocol/packets.md` (section 0x84 Change Password)
