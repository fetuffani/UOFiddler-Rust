# 0x71 - Bulletin Board

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Displays the bulletin board, message headers and message content.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x71 |
| 1 | 2 | u16 | length | Total size. |
| 3 | 1 | u8 | subcommand | 0 = display board, 1 = message header, 2 = message content. |
| 4 | 4 | u32 | boardSerial | Board. |

**Subcommand 0 (display board)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 8 | 30 | ASCII[30] | boardName | Name, padded with 0x00. |

**Subcommand 1 (header)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 8 | 4 | u32 | messageSerial |  |
| 12 | 4 | u32 | parentSerial | 0 if it is the root of the thread. |
| 16 | n | str | poster | String with a size prefix. |
| + | n | str | subject |  |
| + | n | str | time |  |

**Subcommand 2 (content)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 8 | 4 | u32 | messageSerial |  |
| 12 | n | str | poster |  |
| + | n | str | subject |  |
| + | n | str | time |  |
| + | 2 | u16 | body | Author's body. |
| + | 2 | u16 | hue | Author's color. |
| + | 1 | u8 | equipCount | Equipped items. |
| + | 4 | pair[] | equip | `itemId` u16 + `hue` u16, repeated `equipCount` times. |
| + | 1 | u8 | lineCount | Lines. |
| + | n | str[] | lines | `lineCount` strings. |

Notes:

Strings: `len` u8 (includes the terminator) followed by `len - 1` bytes and a 0x00.
In the body (subcommand 2) each line ends with two 0x00 bytes and `len` includes them.
ClassicUO reads the board name in 22 bytes; ServUO writes 30 bytes.
