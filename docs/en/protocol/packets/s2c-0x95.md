# 0x95 - Dye Window
Direction: server -> client. Size: 9 bytes.
Purpose: Opens the color selection window (hue picker).

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x95 |
| 1 | 4 | u32 | serial | Serial of the object to dye |
| 5 | 2 | u16 | hue | ServUO sends 0; Source-X sends the object's current hue |
| 7 | 2 | u16 | itemId | Item id used as preview |

Notes: The client responds with the client-to-server 0x95 packet (chosen hue). ClassicUO ignores the hue field.
