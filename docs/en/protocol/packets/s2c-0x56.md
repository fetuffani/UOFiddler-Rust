# 0x56 - Map Packet (cartography/treasure)

Direction: server -> client. Size: 11 bytes.

Purpose: Pin editing/display commands on a map.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x56 |
| 1 | 4 | u32 | serial | Map item. |
| 5 | 1 | u8 | command | Command (table). |
| 6 | 1 | u8 | editable | Edit state (1 = editable). |
| 7 | 2 | u16 | x | Pin pixel X. |
| 9 | 2 | u16 | y | Pin pixel Y. |

Notes:

| command | Meaning |
|---|---|
| 1 | Add pin |
| 2 | Insert pin |
| 3 | Move pin |
| 4 | Remove pin |
| 5 | Clear pins (ModernUO uses this value when displaying the map) |
| 6 | Edit |
| 7 | Edit response (the client reads `editable` as the plotting state) |

For command 1 the client skips 1 byte (the `editable` field) and reads x and y.
