# 0x24 - Draw/Open Container

Direction: server -> client. Size: 7 or 9 bytes (9 on High Seas clients, 7.0.9.0+).

Purpose: Opens the window of a container, vendor or spellbook.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x24 |
| 1 | 4 | u32 | serial | Container or vendor. |
| 5 | 2 | u16 | gumpId | Container gump; 0x0030 = vendor buy window; 0xFFFF = spellbook (the client opens the spellbook). |
| 7 | 2 | u16 | containerType | Only in the 9-byte variant: 0x007D for containers (ServUO); 0x0000 for the vendor window. |

Notes:

The packets.md table indicates 9 bytes (current variant); the 7-byte variant is sent to clients prior to High Seas.
