# 0x11 - Mobile Status (HP/stats)

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Sends the name, life and (for the player's own character) full attributes of a mobile.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x11 |
| 1 | 2 | u16 | length | Total packet size. |
| 3 | 4 | u32 | serial | Described mobile. |
| 7 | 30 | ASCII[30] | name | Name, terminated/padded with 0x00. |
| 37 | 2 | u16 | hits | Current life (see notes on normalization). |
| 39 | 2 | u16 | hitsMax | Maximum life. |
| 41 | 1 | u8 | canRename | 1 if the player can rename it (pet). |
| 42 | 1 | u8 | type | Status block level (table below). |

**Block type >= 1 (player only)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 43 | 1 | u8 | female | 1 = female. |
| 44 | 2 | u16 | str | Strength. |
| 46 | 2 | u16 | dex | Dexterity. |
| 48 | 2 | u16 | int | Intelligence. |
| 50 | 2 | u16 | stam | Current stamina. |
| 52 | 2 | u16 | stamMax | Maximum stamina. |
| 54 | 2 | u16 | mana | Current mana. |
| 56 | 2 | u16 | manaMax | Maximum mana. |
| 58 | 4 | u32 | gold | Gold. |
| 62 | 2 | i16 | physicalResist | Physical resistance (or armor rating before AOS). |
| 64 | 2 | u16 | weight | Weight. |

**Block type 5 and 6 (inserted after weight)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 66 | 2 | u16 | weightMax | Maximum weight. |
| 68 | 1 | u8 | race | Race + 1. |

**Block type >= 3 (offsets counted for type 3/4; shift by 3 bytes if type >= 5)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 66 | 2 | u16 | statCap | Stat cap. |
| 68 | 1 | u8 | followers | Current followers. |
| 69 | 1 | u8 | followersMax | Maximum followers. |

**Block type >= 4 (follows followersMax)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 2 | i16 | fireResist |  |
| +2 | 2 | i16 | coldResist |  |
| +4 | 2 | i16 | poisonResist |  |
| +6 | 2 | i16 | energyResist |  |
| +8 | 2 | i16 | luck |  |
| +10 | 2 | i16 | damageMin |  |
| +12 | 2 | i16 | damageMax |  |
| +14 | 4 | u32 | tithingPoints | Tithing points. |

**Block type 6 (follows tithingPoints)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 30 | i16[15] | extra | 15 i16 values (see notes). |

Notes:

- `type` 0: the packet ends at offset 43 (43 bytes). Used for mobiles that are not the player's own character; ServUO writes normalized life (hits proportional to a fixed scale and hitsMax equal to the scale) when normalization is active.
- `type` >= 1 (player's own character only) adds the blocks below. Each level includes the previous ones.
- `type`: 3 = Renaissance (70 bytes), 4 = AOS (88 bytes), 5 = ML (91 bytes), 6 = HS/SA with extended status (121 bytes; on the Enhanced Client ServUO writes 29 values instead of 15, Not specified in detail).
- If `type` >= 5 the client reads `weightMax` and `race` before `statCap`; for `type` < 5 the client computes weightMax (7 * (str/2) + 40 from version 5.0.0a; before that str*4 + 25).
- `race`: the server sends RaceID + 1; the client treats 0 as 1.
- `type` 6: the 15 extra i16 values follow this order: maxPhysicalResist, maxFireResist, maxColdResist, maxPoisonResist, maxEnergyResist, defenseChanceIncrease, maxDefenseChanceIncrease, hitChanceIncrease, swingSpeedIncrease, damageIncrease, lowerReagentCost, spellDamageIncrease, fasterCastRecovery, fasterCasting, lowerManaCost.
- If the packet has no stats, the client keeps the previous values.
