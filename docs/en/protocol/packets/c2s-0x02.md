# 0x02 - Move Request

Direction: client -> server. Size: 7 bytes (fixed). Available: in game.

Purpose: Requests to move the character one step.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x02 |
| 1 | 1 | u8 | direction | bits 0-2 = direction; bit 0x80 = running |
| 2 | 1 | u8 | sequence | step sequence number |
| 3 | 4 | u32 | fastwalkKey | fastwalk key; ignored by current servers |

Notes:

Direction (bits 0-2): 0 north, 1 northeast (right), 2 east, 3 southeast (down), 4 south, 5 southwest (left), 6 west, 7 northwest (up).

Sequence: the first step after login, resync, or rejection uses 0. After each accepted step, the next one uses sequence + 1; upon reaching 255 it wraps to 1 (never to 0). If the server has no active sequence (0) and receives a sequence other than 0, it rejects the step.

Response: 0x22 Move Acknowledge (3 bytes) if accepted, or 0x21 Move Reject (8 bytes) if rejected; after a rejection the server resets the sequence and the client must restart with 0 (normally after sending 0x22 Resynchronize).
