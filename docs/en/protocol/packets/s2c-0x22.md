# 0x22 - Move Acknowledge

Direction: server -> client. Size: 3 bytes.

Purpose: Confirms a step and informs the player's notoriety.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x22 |
| 1 | 1 | u8 | sequence | Confirmed sequence. |
| 2 | 1 | u8 | notoriety | Notoriety (table); the client removes bit 0x40 and treats 0 or >= 8 as 1. |

Notes:

| Value | Notoriety |
|---|---|
| 1 | Innocent |
| 2 | Ally |
| 3 | Gray (attackable) |
| 4 | Criminal |
| 5 | Enemy |
| 6 | Murderer |
| 7 | Invulnerable |
