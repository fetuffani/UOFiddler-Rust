# 0x93 - Book Header (old)
Direction: server -> client. Size: 99 bytes.
Purpose: Opens a book with title and author, in the format used before 0xD4.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x93 |
| 1 | 4 | u32 | serial | Book serial |
| 5 | 1 | u8 | writable | 1 if the book is editable |
| 6 | 1 | u8 | writable2 | Repeats the previous value (Source-X); ClassicUO ignores the byte |
| 7 | 2 | u16 | pages | Number of pages |
| 9 | 60 | ascii[60] | title | Title, padded with 0x00 |
| 69 | 30 | ascii[30] | author | Author, padded with 0x00 |

Notes: The client responds by requesting the content of page 1. The variant with variable-length strings is 0xD4.

## Implementation reference
- Source-X: `src/network/send.cpp` (`PacketDisplayBook`)
- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs` (`OpenBook`)
