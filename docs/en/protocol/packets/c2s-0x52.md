# 0x52 - Board Post Message

Direction: client -> server. Size: variable (id + u16 length + payload). Available: Not specified.

Purpose: Post to a message board.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x52 |
| 1 | 2 | u16 | length | total packet size |
| 3 | n | u8[] | data | Not specified |

Notes:

No reference implementation handles this id. The active message board actions use id 0x71.

Implementation reference:

- ClassicUO size table: `src/ClassicUO.Client/Network/PacketsTable.cs` (variable)
