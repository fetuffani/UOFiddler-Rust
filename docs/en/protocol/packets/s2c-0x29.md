# 0x29 - Drop Item Approved

Direction: server -> client. Size: 1 byte.

Purpose: Confirms the drop of an item (sent to Kingdom Reborn clients).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x29 |

Notes:

No fields. The client clears the held item state.

## Implementation reference

- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketDropAccepted` (KR clients only)
- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs`: `DropItemAccepted`
