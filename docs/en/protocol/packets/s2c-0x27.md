# 0x27 - Reject Move Item

Direction: server -> client. Size: 2 bytes.

Purpose: Rejects an attempt to pick up an item.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x27 |
| 1 | 1 | u8 | reason | Reason (table). |

Notes:

| Value | Reason |
|---|---|
| 0 | Cannot pick up |
| 1 | Out of range |
| 2 | Out of sight |
| 3 | Attempt to steal |
| 4 | Already holding an item |
| 5 | Unspecified |
