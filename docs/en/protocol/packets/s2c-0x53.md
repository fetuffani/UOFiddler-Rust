# 0x53 - Reject Character Logon / Popup message

Direction: server -> client. Size: 2 bytes.

Purpose: Displays a warning/rejection message when trying to enter with a character.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x53 |
| 1 | 1 | u8 | code | Code (table). |

Notes:

| Value | Message |
|---|---|
| 0 | Incorrect password |
| 1 | Character does not exist |
| 2 | Character already exists |
| 3 | Other |
| 4 | Other 2 |
| 5 | Character is already in the world |
| 6 | Synchronization error |
| 7 | Inactivity warning |
| 8 | Could not connect to the server |
| 9 | Character transfer |
| 10 | Invalid name |

ServUO defines only the values 1, 2, 5, 6 and 7; the complete list comes from Source-X.

## Implementation reference

- ServUO: `Server/Network/Packets.cs`: `PopupMessage`, `PMMessage`
- ModernUO: `Projects/Server/Network/Packets/OutgoingAccountPackets.cs` (`SendPopupMessage`)
- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketWarningMessage`
- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs`: `ReceiveLoginRejection`
