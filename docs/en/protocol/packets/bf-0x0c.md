# 0xBF / 0x0C - Close status bar
Direction: both. Size: fixed 9 bytes total.
Purpose: the client notifies that it closed a mobile's status window; ClassicUO also accepts the same packet to close the status bar.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 9 |
| 3 | 2 | u16 | subcommand | 0x000C |
| 5 | 4 | u32 | serial | Serial of the mobile whose bar was closed |
