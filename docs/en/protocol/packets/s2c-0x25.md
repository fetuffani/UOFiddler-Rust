# 0x25 - Add Item To Container

Direction: server -> client. Size: 21 bytes (20 bytes before client 6.0.1.7).

Purpose: Adds an item to an open container or to the secure trade window.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x25 |
| 1 | 4 | u32 | serial | Item. |
| 5 | 2 | u16 | graphic | ItemID. |
| 7 | 1 | u8 | graphicOffset | 0; added to graphic by the client. |
| 8 | 2 | u16 | amount | Quantity (the client uses at least 1). |
| 10 | 2 | u16 | x | X position in the container. |
| 12 | 2 | u16 | y | Y position in the container. |
| 14 | 1 | u8 | gridIndex | Only from client 6.0.1.7 onward (container grid). |
| 15 | 4 | u32 | containerSerial | Parent container. |
| 19 | 2 | u16 | hue | Color. |

Notes:

Without `gridIndex` (clients before 6.0.1.7), `containerSerial` is at offset 14 and `hue` at 18, for 20 bytes in total. In secure trade (0x6F), another player's equipped item uses this same packet, with the mobile's serial in place of the container.
