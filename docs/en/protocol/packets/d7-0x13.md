# 0xD7 / 0x13 - House: place roof
Direction: client -> server. Size: fixed 30 bytes total.
Purpose: adds a roof piece (Samurai Empire onward).

Layout identical to 0x05 (itemId, x, y, z in `enc32`), with `subcommand = 0x0013`.

Notes: ServUO only accepts it from players with `Core.SE`; GMs always. Z must be a multiple of 3 between -3 and 12, otherwise it becomes -3; existing roofs in the same column and floor are replaced.
