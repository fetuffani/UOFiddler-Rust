# 0x54 - Play Sound Effect

Direction: server -> client. Size: 12 bytes.

Purpose: Plays a sound effect at a position.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x54 |
| 1 | 1 | u8 | flags | 1 in ServUO (the client ignores it). |
| 2 | 2 | u16 | soundId | Sound index. |
| 4 | 2 | u16 | volume | 0 in ServUO. |
| 6 | 2 | u16 | x |  |
| 8 | 2 | u16 | y |  |
| 10 | 2 | i16 | z |  |

## Implementation reference

- ServUO: `Server/Network/Packets.cs`: `PlaySound`
- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketPlaySound`
- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs`: `PlaySoundEffect`
