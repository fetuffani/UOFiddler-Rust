# 0x75 - RenameRequest

Direction: client -> server. Size: 35 bytes (fixed). Available: in game.

Purpose: Renames a mobile (for example a pet).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x75 |
| 1 | 4 | u32 | serial | mobile serial |
| 5 | 30 | char[30] | name | new name, ASCII padded with NUL |
