# 0xBF / 0x08 - Change map
Direction: server -> client. Size: fixed 6 bytes total.
Purpose: informs the player's current map (facet).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 6 |
| 3 | 2 | u16 | subcommand | 0x0008 |
| 5 | 1 | u8 | mapId | Map index (0 Felucca, 1 Trammel, 2 Ilshenar, 3 Malas, 4 Tokuno, 5 Ter Mur) |

Notes: ModernUO example: `BF 00 06 00 08 <mapId>`. The index names above follow the map numbering used by ServUO/ModernUO (`Map.MapID`); the packet itself only carries the byte.
