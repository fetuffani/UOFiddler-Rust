# 0x65 - Set Weather

Direction: server -> client. Size: 4 bytes.

Purpose: Sets the weather displayed on the client.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x65 |
| 1 | 1 | u8 | type | Weather type (table). |
| 2 | 1 | u8 | count | Intensity/number of particles. |
| 3 | 1 | u8 | temperature | Temperature. |

Notes:

| type | Weather |
|---|---|
| 0 | Rain |
| 1 | Storm approaching |
| 2 | Snow |
| 3 | Storm forming |
| 0xFE, 0xFF | Invalid (no weather) |

The client only reads `count` and `temperature` when the type differs from the current weather.
