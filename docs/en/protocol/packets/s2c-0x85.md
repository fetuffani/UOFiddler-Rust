# 0x85 - Character Delete Result
Direction: server -> client. Size: 2 bytes.
Purpose: Reports the result of a character deletion request.

Conventions: offsets counted from the first byte of the packet (the id); integers of more than one byte are big-endian; u8/u16/u32 are unsigned, i8/i16/i32 are signed.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x85 |
| 1 | 1 | u8 | result | Result code |

Notes: Values (`DeleteResultType`): 0 PasswordInvalid, 1 CharNotExist, 2 CharBeingPlayed, 3 CharTooYoung, 4 CharQueued, 5 BadRequest. On success the server then sends 0x86 with the updated list.
