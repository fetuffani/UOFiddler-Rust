# 0xBF / 0x2B - Animation by partial serial
Direction: server -> client. Size: fixed 9 bytes total.
Purpose: sets the animation/frame of a mobile identified by the low 16 bits of its serial (handled only by ClassicUO).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 9 |
| 3 | 2 | u16 | subcommand | 0x002B |
| 5 | 2 | u16 | serialLow | Low 16 bits of the serial |
| 7 | 1 | u8 | animation | Animation id |
| 8 | 1 | u8 | frame | Frame quantity/index |

Notes: this subcommand appears only in ClassicUO; ServUO, ModernUO and Source-X do not send it.
