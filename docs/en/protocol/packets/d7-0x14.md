# 0xD7 / 0x14 - House: remove roof
Direction: client -> server. Size: fixed 30 bytes total.
Purpose: removes a roof piece.

Layout identical to 0x05, with `subcommand = 0x0014`. The server ignores it (and resends the state) if the graphic does not have the Roof flag.
