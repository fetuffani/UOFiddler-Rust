# 0x78 - Mobile Incoming (mobile appears + equipment)

Direction: server -> client. Size: variable (id + u16 length + payload).

Purpose: Creates a mobile on the client with its equipped items.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x78 |
| 1 | 2 | u16 | length | Total size. |
| 3 | 4 | u32 | serial |  |
| 7 | 2 | u16 | body |  |
| 9 | 2 | u16 | x |  |
| 11 | 2 | u16 | y |  |
| 13 | 1 | i8 | z |  |
| 14 | 1 | u8 | direction |  |
| 15 | 2 | u16 | hue |  |
| 17 | 1 | u8 | flags | See 0x77. |
| 18 | 1 | u8 | notoriety |  |
| 19 | n | item[] | equipment | Equipped items (format below). |
| end | 4 | u32 | terminator | 0x00000000. |

**Equipped item (new format, 9 bytes)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 4 | u32 | serial | Item. |
| +4 | 2 | u16 | graphic | ItemID. |
| +6 | 1 | u8 | layer | Layer. |
| +7 | 2 | u16 | hue | Color. |

**Equipped item (old format)**

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| +0 | 4 | u32 | serial |  |
| +4 | 2 | u16 | graphic | Bit 15 = hue present; ItemID = graphic & 0x7FFF. |
| +6 | 1 | u8 | layer |  |
| +7 | 2 | u16 | hue | Only if graphic & 0x8000. |

Notes:

- Minimum size: 23 bytes (no items).
- Hair, beard and face are sent as items with a synthetic serial in the Hair, FacialHair and Face layers.
- Clients 7.0.33.1+ (`item_hue` always present): each item has 9 bytes. Earlier clients: `graphic` with bit 0x8000 signals that the u16 `hue` follows; the item has 7 or 9 bytes.
- Decision example in ServUO: `NewMobileIncoming` (hue always) or old format (bit 0x8000 in graphic when hue != 0).
