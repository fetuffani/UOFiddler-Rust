# 0x03 - Talk (ASCII)

Direction: client -> server. Size: variable (id + u16 length + payload). Available: in game.

Purpose: Sends speech in ASCII (older clients).

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x03 |
| 1 | 2 | u16 | length | total packet size |
| 3 | 1 | u8 | type | speech type |
| 4 | 2 | u16 | hue | text color |
| 6 | 2 | u16 | font | font |
| 8 | n | char[] | text | NUL-terminated ASCII (n = length - 8) |

Notes:

Types: 0 normal, 2 emote, 8 whisper, 9 yell, 13 guild, 14 alliance, 15 command (see also 0xAD, which uses the same enumeration).
The server discards empty text or text longer than 128 characters.
