# 0xBF / 0x26 - Speed mode
Direction: server -> client. Size: fixed 6 bytes total.
Purpose: sets the player's movement speed mode.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 6 |
| 3 | 2 | u16 | subcommand | 0x0026 |
| 5 | 1 | u8 | mode | Table below |

| mode | Name (ServUO) | Behavior in ClassicUO |
|---|---|---|
| 0 | Disable | Normal |
| 1 | MountSpeed | Fast when mounted |
| 2 | WalkSpeed | Cannot run |
| 3 | WalkSpeedFast | Fast when mounted and cannot run |
| 4 | TeleportSpeed | Values above 3 become 0 in ClassicUO |
