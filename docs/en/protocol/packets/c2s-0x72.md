# 0x72 - Request War Mode

Direction: client -> server. Size: 5 bytes (fixed). Available: in game.

Purpose: Turns combat mode on or off.

| Offset | Size | Type | Field | Description |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x72 |
| 1 | 1 | u8 | warmode | 0 = peace; 1 = war |
| 2 | 3 | u8[3] | reserved | ignored by the server; the reference client sends 0x32 0x00 0x00 |

Notes:

Response: 0x72 from the server (same id, reverse direction) confirming the state.

Implementation reference:

- ServUO: `Server/Network/PacketHandlers.cs` (`SetWarMode`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingPlayerPackets.cs` (`SetWarMode`)
