# 0x47 - NewTerrain

Direção: cliente -> servidor. Tamanho: 11 bytes (fixo). Disponível: em jogo (somente cliente God).

Finalidade: Edita terreno (cliente God).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x47 |
| 1 | 2 | i16 | x | posição X |
| 3 | 2 | i16 | y | posição Y |
| 5 | 2 | u16 | tileId | id do tile |
| 7 | 2 | i16 | width | largura |
| 9 | 2 | i16 | height | altura |

Notas:

O ServUO apenas registra o conteúdo.
