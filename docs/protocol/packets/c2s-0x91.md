# 0x91 - Game Server Login

Direção: cliente -> servidor. Tamanho: 65 bytes (fixo). Disponível: antes do login (conexão ao servidor de jogo).

Finalidade: Autentica no servidor de jogo usando a chave recebida em 0x8C.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x91 |
| 1 | 4 | u32 | authId | chave de autenticação recebida em 0x8C Connect To Game Server |
| 5 | 30 | char[30] | account | nome da conta |
| 35 | 30 | char[30] | password | senha |

Notas:

Resposta: 0xB9 (recursos habilitados) e lista de personagens 0xA9. É o primeiro pacote da conexão com o servidor de jogo depois do seed; um segundo 0x91 na mesma conexão é recusado.
