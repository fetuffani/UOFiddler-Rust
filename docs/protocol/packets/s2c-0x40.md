# 0x40 - Update Terrain (God client; UltimaLive)

Direção: servidor -> cliente. Tamanho: 201 bytes.

Finalidade: UltimaLive: envia o terreno (64 células) de um bloco do mapa.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x40 |
| 1 | 4 | u32 | blockNumber | Número do bloco. |
| 5 | 192 | cell[64] | tiles | 64 células de 3 bytes: `tileId` u16 + `z` i8. |
| 197 | 3 | u8[3] | padding | Zeros. |
| 200 | 1 | u8 | mapId | Mapa. |
