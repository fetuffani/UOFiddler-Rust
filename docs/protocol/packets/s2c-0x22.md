# 0x22 - Move Acknowledge

Direção: servidor -> cliente. Tamanho: 3 bytes.

Finalidade: Confirma um passo e informa a notoriedade do jogador.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x22 |
| 1 | 1 | u8 | sequence | Sequência confirmada. |
| 2 | 1 | u8 | notoriety | Notoriedade (tabela); o cliente remove o bit 0x40 e trata 0 ou >= 8 como 1. |

Notas:

| Valor | Notoriedade |
|---|---|
| 1 | Inocente |
| 2 | Aliado |
| 3 | Cinza (atacável) |
| 4 | Criminoso |
| 5 | Inimigo |
| 6 | Assassino |
| 7 | Invulnerável |
