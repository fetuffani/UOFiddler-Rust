# 0x11 - Mobile Status (HP/stats)

Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload).

Finalidade: Envia nome, vida e (para o próprio jogador) atributos completos de um mobile.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x11 |
| 1 | 2 | u16 | length | Tamanho total do pacote. |
| 3 | 4 | u32 | serial | Mobile descrito. |
| 7 | 30 | ASCII[30] | name | Nome, terminado/preenchido com 0x00. |
| 37 | 2 | u16 | hits | Vida atual (ver notas sobre normalização). |
| 39 | 2 | u16 | hitsMax | Vida máxima. |
| 41 | 1 | u8 | canRename | 1 se o jogador pode renomear (animal de estimação). |
| 42 | 1 | u8 | type | Nível do bloco de status (tabela abaixo). |

**Bloco type >= 1 (apenas jogador)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 43 | 1 | u8 | female | 1 = feminino. |
| 44 | 2 | u16 | str | Força. |
| 46 | 2 | u16 | dex | Destreza. |
| 48 | 2 | u16 | int | Inteligência. |
| 50 | 2 | u16 | stam | Stamina atual. |
| 52 | 2 | u16 | stamMax | Stamina máxima. |
| 54 | 2 | u16 | mana | Mana atual. |
| 56 | 2 | u16 | manaMax | Mana máxima. |
| 58 | 4 | u32 | gold | Ouro. |
| 62 | 2 | i16 | physicalResist | Resistência física (ou armor rating antes do AOS). |
| 64 | 2 | u16 | weight | Peso. |

**Bloco type 5 e 6 (inserido após weight)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 66 | 2 | u16 | weightMax | Peso máximo. |
| 68 | 1 | u8 | race | Raça + 1. |

**Bloco type >= 3 (offsets contados para type 3/4; deslocar 3 bytes se type >= 5)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 66 | 2 | u16 | statCap | Limite de atributos. |
| 68 | 1 | u8 | followers | Seguidores atuais. |
| 69 | 1 | u8 | followersMax | Seguidores máximos. |

**Bloco type >= 4 (segue followersMax)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| +0 | 2 | i16 | fireResist |  |
| +2 | 2 | i16 | coldResist |  |
| +4 | 2 | i16 | poisonResist |  |
| +6 | 2 | i16 | energyResist |  |
| +8 | 2 | i16 | luck |  |
| +10 | 2 | i16 | damageMin |  |
| +12 | 2 | i16 | damageMax |  |
| +14 | 4 | u32 | tithingPoints | Pontos de dízimo. |

**Bloco type 6 (segue tithingPoints)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| +0 | 30 | i16[15] | extra | 15 valores i16 (ver notas). |

Notas:

- `type` 0: o pacote termina no offset 43 (43 bytes). Usado para mobiles que não são o próprio jogador; ServUO escreve vida normalizada (hits proporcional a uma escala fixa e hitsMax igual à escala) quando a normalização está ativa.
- `type` >= 1 (somente para o próprio jogador) acrescenta os blocos abaixo. Cada nível inclui os anteriores.
- `type`: 3 = Renaissance (70 bytes), 4 = AOS (88 bytes), 5 = ML (91 bytes), 6 = HS/SA com status estendido (121 bytes; no Enhanced Client o ServUO escreve 29 valores em vez de 15, Não especificado em detalhe).
- Se `type` >= 5 o cliente lê `weightMax` e `race` antes de `statCap`; para `type` < 5 o cliente calcula weightMax (7 * (str/2) + 40 a partir da versão 5.0.0a; antes str*4 + 25).
- `race`: o servidor envia RaceID + 1; o cliente trata 0 como 1.
- `type` 6: os 15 valores i16 extras seguem a ordem: maxPhysicalResist, maxFireResist, maxColdResist, maxPoisonResist, maxEnergyResist, defenseChanceIncrease, maxDefenseChanceIncrease, hitChanceIncrease, swingSpeedIncrease, damageIncrease, lowerReagentCost, spellDamageIncrease, fasterCastRecovery, fasterCasting, lowerManaCost.
- Sem estatísticas no pacote o cliente mantém os valores anteriores.
