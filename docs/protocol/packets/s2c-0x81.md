# 0x81 - Change Character
Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload; length é o tamanho total do pacote).
Finalidade: Lista os personagens da conta para o jogador trocar de personagem.

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x81 |
| 1 | 2 | u16 | length | Tamanho total do pacote, incluindo id e este campo |
| 3 | 1 | u8 | count | Quantidade de slots ocupados |
| 4 | 1 | u8 | reserved | 0 |
| 5 | 60 x N | entry[] | characters | N = comprimento da conta (ServUO/ModernUO: `5 + 60*N` bytes no total) |

Notas: Cada entrada ocupa 60 bytes: nome ASCII de 30 bytes preenchido com 0x00, seguido de 30 bytes zerados (campo de senha, sempre vazio). Slot livre = 60 bytes zerados. O ClassicUO não registra handler para 0x81; o Source-X não envia este pacote a clientes KR/Enhanced.
