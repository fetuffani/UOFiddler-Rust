# 0xBF / 0x04 - Fechar gump genérico
Direção: servidor -> cliente. Tamanho: fixo 13 bytes total.
Finalidade: fecha um gump aberto pelo servidor, opcionalmente simulando o clique de um botão.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0004 |
| 5 | 4 | u32 | gumpTypeId | Tipo (TypeID) do gump a fechar |
| 9 | 4 | u32 | buttonId | Botão a "pressionar" ao fechar; 0 = só fecha |

Notas: com `buttonId != 0` o cliente executa o clique do botão e fecha o gump; com 0 apenas guarda/remove a posição e fecha.
