# 0x31 - Attack Ended / Pet Window

Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload).

Finalidade: Na implementação do ServUO, lista os seguidores do jogador (janela de pets).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x31 |
| 1 | 2 | u16 | length | Tamanho total (8 + 5 * count). |
| 3 | 4 | u32 | ownerSerial | Dono. |
| 7 | 1 | u8 | count | Número de seguidores. |
| 8+5n | 4 | u32 | followerSerial | Serial do seguidor. |
| 12+5n | 1 | u8 | flag | 0x01. |

Notas:

- Divergência: packets.md nomeia 0x31 como `Attack Ended` com tamanho variável, enquanto a tabela de comprimentos do ClassicUO indica 1 byte e o ServUO emite o layout acima. O significado real do id não é confirmado.
- Entradas: `count` repetições de 5 bytes.
