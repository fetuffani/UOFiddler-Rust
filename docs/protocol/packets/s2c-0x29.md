# 0x29 - Drop Item Approved

Direção: servidor -> cliente. Tamanho: 1 byte.

Finalidade: Confirma o drop de um item (enviado a clientes Kingdom Reborn).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x29 |

Notas:

Sem campos. O cliente limpa o estado de item segurado.

## Referência de implementação

- Source-X: `src/network/send.cpp`, `src/network/send.h`: `PacketDropAccepted` (somente clientes KR)
- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs`: `DropItemAccepted`
