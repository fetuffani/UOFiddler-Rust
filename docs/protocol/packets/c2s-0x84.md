# 0x84 - Change Password

Direção: cliente -> servidor. Tamanho: 69 bytes (fixo). Disponível: antes do login.

Finalidade: Troca a senha da conta.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x84 |
| 1 | 30 | char[30] | currentPassword | senha atual, ASCII |
| 31 | 30 | char[30] | newPassword | nova senha, ASCII |
| 61 | 4 | u32 | unknown | Não especificado |
| 65 | 4 | u32 | localIp | IPv4 local do cliente |

Notas:

Nenhum servidor de referência trata este id; o layout vem da tabela de pacotes do cliente.

Referência de implementação:

- Tabela de pacotes: `docs/protocol/packets.md` (seção 0x84 Change Password)
- Tabela de tamanhos do ClassicUO: `src/ClassicUO.Client/Network/PacketsTable.cs` (69 bytes)
