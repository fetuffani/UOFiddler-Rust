# 0x17 - Health Bar Status Update

Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload).

Finalidade: Atualiza a cor da barra de vida de um mobile (veneno, barra amarela).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x17 |
| 1 | 2 | u16 | length | Tamanho total (7 + 3 * count; 12 com count = 1). |
| 3 | 4 | u32 | serial | Mobile. |
| 7 | 2 | u16 | count | Número de entradas. |
| 9+3n | 2 | u16 | type | Tipo da barra: 1 = veneno, 2 = barra amarela (invulnerável/abençoado), 3 = desconhecido. |
| 11+3n | 1 | u8 | enabled | 0 = desliga; para veneno ServUO envia nível + 1; para amarela envia 1 ou 0. |

Notas:

- Mesmo layout do 0x16, enviado a clientes clássicos.
- Com cliente >= 7.0.0.0 o veneno é aplicado como estado SA; antes, como flag Poisoned do mobile.
