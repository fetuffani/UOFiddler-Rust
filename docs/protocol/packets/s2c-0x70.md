# 0x70 - Graphical Effect

Direção: servidor -> cliente. Tamanho: 28 bytes.

Finalidade: Exibe um efeito gráfico (projétil, raio, efeito fixo).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x70 |
| 1 | 1 | u8 | type | 0 = move da origem ao destino, 1 = raio, 2 = fixo na posição, 3 = fixo no mobile de origem. |
| 2 | 4 | u32 | sourceSerial |  |
| 6 | 4 | u32 | targetSerial |  |
| 10 | 2 | u16 | graphic | ItemID do efeito. |
| 12 | 2 | u16 | srcX |  |
| 14 | 2 | u16 | srcY |  |
| 16 | 1 | i8 | srcZ |  |
| 17 | 2 | u16 | dstX |  |
| 19 | 2 | u16 | dstY |  |
| 21 | 1 | i8 | dstZ |  |
| 22 | 1 | u8 | speed |  |
| 23 | 1 | u8 | duration |  |
| 24 | 2 | u16 | unknown | 0. |
| 26 | 1 | bool | fixedDirection |  |
| 27 | 1 | bool | explode |  |

Notas:

O 0xC0 (efeito com cor) tem o mesmo início, seguido de hue e render mode.
