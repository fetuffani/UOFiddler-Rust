# 0x96 - GameCentralMoniter

Direção: cliente -> servidor. Tamanho: variável (id + u16 length + payload). Disponível: em jogo (somente cliente God).

Finalidade: Monitor central de jogo (cliente God).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x96 |
| 1 | 2 | u16 | length | tamanho total |
| 3 | 1 | u8 | type | tipo |
| 4 | 4 | i32 | value | número |

Notas:

O ServUO apenas registra o conteúdo.

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`GameCentralMoniter`)
