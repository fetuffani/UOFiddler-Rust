# 0x33 - Pause/Resume Client

Direção: servidor -> cliente. Tamanho: 2 bytes.

Finalidade: Pausa ou retoma o processamento do cliente.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x33 |
| 1 | 1 | u8 | state | Não especificado. |

Notas:

O conteúdo do byte não é definido pelas implementações consultadas; o tamanho 2 vem da tabela do ClassicUO.
