# 0x83 - DeleteCharacter

Direção: cliente -> servidor. Tamanho: 39 bytes (fixo). Disponível: antes do login.

Finalidade: Apaga um personagem da conta.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x83 |
| 1 | 30 | char[30] | password | senha de confirmação (o cliente de referência envia zeros) |
| 31 | 4 | u32 | slot | slot do personagem |
| 35 | 4 | u32 | clientIp | IPv4 do cliente |

Notas:

Resposta: lista de personagens atualizada (0xA9) ou mensagem de erro, conforme o servidor.
