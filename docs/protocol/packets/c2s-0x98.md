# 0x98 - MobileNameRequest

Direção: cliente -> servidor. Tamanho: variável (id + u16 length + payload). Disponível: em jogo.

Finalidade: Pede o nome de um ou mais mobiles.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x98 |
| 1 | 2 | u16 | length | 3 + 4 x n |
| 3 | 4 | u32 | serial | serial do mobile (repete-se n vezes) |

Notas:

O Source-X processa todos os serials da lista; o ServUO lê apenas o primeiro. Resposta: 0x98 Mobile Name.

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`MobileNameRequest`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingMobilePackets.cs` (`MobileNameRequest`)
- Source-X: `src/network/receive.cpp` (`PacketAllNamesReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_NameRequest`)
