# 0xD7 / 0x04 - Casa: commit
Direção: cliente -> servidor. Tamanho: fixo 10 bytes total.
Finalidade: confirma o design e sai do modo de customização.

Layout idêntico ao 0x02, com `subcommand = 0x0004`. O servidor calcula o custo, debita/credita o banco, encerra a customização (0xBF/0x20 tipo 5) e reenvia o estado final.

## Exemplo

Jogador com serial 0x00000001 confirma o design:

```
D7 00 0A 00 00 00 01 00 04 0A
```

| Bytes | Significado |
|---|---|
| `D7` | id |
| `00 0A` | length = 10 |
| `00 00 00 01` | serial do jogador |
| `00 04` | subcommand = commit |
| `0A` | terminador |

Colocar um item (0xD7 / 0x06), gráfico 0x0001, x = 2, y = 3, 25 bytes:

```
D7 00 19 00 00 00 01 00 06 00 00 00 00 01 00 00 00 00 02 00 00 00 00 03 0A
```

Cada valor é `00` + `u32`: `00 00 00 00 01`, `00 00 00 00 02`, `00 00 00 00 03`.
