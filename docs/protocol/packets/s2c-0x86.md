# 0x86 - Character List Update
Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload; length é o tamanho total do pacote).
Finalidade: Reenvia a lista de personagens da conta após criar ou excluir um personagem.

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x86 |
| 1 | 2 | u16 | length | Tamanho total do pacote, incluindo id e este campo |
| 3 | 1 | u8 | count | Quantidade de slots enviados |
| 4 | 60 x count | entry[] | characters | Ver notas |

Notas: Cada entrada ocupa 60 bytes: nome ASCII de 30 bytes preenchido com 0x00, seguido de 30 bytes zerados (campo de senha, sempre vazio). Slot livre = 60 bytes zerados. ServUO/ModernUO enviam `count = max(maior slot ocupado + 1, limite da conta, 5)`; o tamanho total é `4 + 60*count`.
