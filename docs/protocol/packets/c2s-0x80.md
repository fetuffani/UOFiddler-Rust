# 0x80 - Login Request

Direção: cliente -> servidor. Tamanho: 62 bytes (fixo). Disponível: antes do login.

Finalidade: Autentica a conta no servidor de login.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x80 |
| 1 | 30 | char[30] | account | nome da conta, ASCII com NUL |
| 31 | 30 | char[30] | password | senha, ASCII com NUL |
| 61 | 1 | u8 | nextLoginKey | valor de NextLoginKey do uo.cfg; o cliente de referência envia 0xFF |

Notas:

Resposta: 0xA8 Game Server List em sucesso; 0x82 Login Denied (motivo de 1 byte) em falha.
