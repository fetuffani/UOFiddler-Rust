# 0xD7 / 0x0C - Casa: sair do designer
Direção: cliente -> servidor. Tamanho: fixo 10 bytes total.
Finalidade: fecha a janela de design sem confirmar.

Layout idêntico ao 0x02, com `subcommand = 0x000C`. O servidor encerra a customização (0xBF/0x20 tipo 5), reenvia o estado visível da casa e move quem estiver dentro para fora.
