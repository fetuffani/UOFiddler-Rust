# 0xD7 / 0x0D - Casa: colocar escada (multi)
Direção: cliente -> servidor. Tamanho: fixo 25 bytes total.
Finalidade: adiciona uma escada (peça multi de vários tiles).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 25 |
| 3 | 4 | u32 | playerSerial | Jogador |
| 7 | 2 | u16 | subcommand | 0x000D |
| 9 | 5 | enc32 | multiId | Id de multi da escada (o Source-X soma `ITEMID_MULTI` ao valor lido) |
| 14 | 5 | enc32 | x | Deslocamento X |
| 19 | 5 | enc32 | y | Deslocamento Y |
| 24 | 1 | u8 | terminator | 0x0A |

Notas: o ServUO valida o id como multi de escada; se inválido, reenvia o estado.
