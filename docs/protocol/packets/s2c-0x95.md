# 0x95 - Dye Window
Direção: servidor -> cliente. Tamanho: 9 bytes.
Finalidade: Abre a janela de seleção de cor (hue picker).

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x95 |
| 1 | 4 | u32 | serial | Serial do objeto a tingir |
| 5 | 2 | u16 | hue | ServUO envia 0; Source-X envia o hue atual do objeto |
| 7 | 2 | u16 | itemId | Id de item usado como pré-visualização |

Notas: O cliente responde com o pacote 0x95 de cliente para servidor (hue escolhido). O ClassicUO ignora o campo hue.
