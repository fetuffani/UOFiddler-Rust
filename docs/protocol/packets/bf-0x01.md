# 0xBF / 0x01 - Fastwalk: inicializar pilha de chaves
Direção: servidor -> cliente. Tamanho: fixo 29 bytes total.
Finalidade: preenche as seis chaves da pilha de prevenção de fast walk.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 29 |
| 3 | 2 | u16 | subcommand | 0x0001 |
| 5 | 24 | u32[6] | keys | Seis chaves; ServUO envia todas com valor 0 |

Notas: o cliente armazena as seis chaves e as consome a cada passo (ver 0x02).
