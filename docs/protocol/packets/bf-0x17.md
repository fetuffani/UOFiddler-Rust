# 0xBF / 0x17 - Tópico de ajuda (Codex of Wisdom)
Direção: servidor -> cliente. Tamanho: fixo 11 bytes total.
Finalidade: abre/ativa um tópico do Codex of Wisdom.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0017 |
| 5 | 1 | u8 | command | 1 |
| 6 | 4 | u32 | topicId | Id do tópico |
| 10 | 1 | u8 | display | 1 = abrir/forçar exibição, 0 = apenas marcar |
