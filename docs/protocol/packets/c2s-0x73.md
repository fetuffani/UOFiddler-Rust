# 0x73 - Ping

Direção: cliente -> servidor. Tamanho: 2 bytes (fixo). Disponível: antes do login e em jogo.

Finalidade: Mede a latência.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x73 |
| 1 | 1 | u8 | value | contador/valor arbitrário |

Notas:

Resposta: pacote 0x73 (2 bytes) com o mesmo valor.
