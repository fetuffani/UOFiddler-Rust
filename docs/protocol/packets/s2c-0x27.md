# 0x27 - Reject Move Item

Direção: servidor -> cliente. Tamanho: 2 bytes.

Finalidade: Rejeita a tentativa de pegar um item.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x27 |
| 1 | 1 | u8 | reason | Motivo (tabela). |

Notas:

| Valor | Motivo |
|---|---|
| 0 | Não pode pegar |
| 1 | Fora de alcance |
| 2 | Fora de visão |
| 3 | Tentativa de roubo |
| 4 | Já está segurando um item |
| 5 | Inespecífico |
