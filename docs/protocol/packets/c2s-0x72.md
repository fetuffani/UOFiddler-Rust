# 0x72 - Request War Mode

Direção: cliente -> servidor. Tamanho: 5 bytes (fixo). Disponível: em jogo.

Finalidade: Liga ou desliga o modo de combate.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x72 |
| 1 | 1 | u8 | warmode | 0 = paz; 1 = guerra |
| 2 | 3 | u8[3] | reservado | ignorado pelo servidor; o cliente de referência envia 0x32 0x00 0x00 |

Notas:

Resposta: 0x72 do servidor (mesmo id, sentido inverso) confirmando o estado.

- ModernUO: `Projects/UOContent/Network/Packets/IncomingPlayerPackets.cs` (`SetWarMode`)
