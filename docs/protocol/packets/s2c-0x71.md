# 0x71 - Bulletin Board

Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload).

Finalidade: Exibe o quadro de avisos, cabeçalhos e conteúdo de mensagens.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x71 |
| 1 | 2 | u16 | length | Tamanho total. |
| 3 | 1 | u8 | subcommand | 0 = exibir quadro, 1 = cabeçalho de mensagem, 2 = conteúdo de mensagem. |
| 4 | 4 | u32 | boardSerial | Quadro. |

**Subcomando 0 (exibir quadro)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 8 | 30 | ASCII[30] | boardName | Nome, preenchido com 0x00. |

**Subcomando 1 (cabeçalho)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 8 | 4 | u32 | messageSerial |  |
| 12 | 4 | u32 | parentSerial | 0 se for a raiz da thread. |
| 16 | n | str | poster | String com prefixo de tamanho. |
| + | n | str | subject |  |
| + | n | str | time |  |

**Subcomando 2 (conteúdo)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 8 | 4 | u32 | messageSerial |  |
| 12 | n | str | poster |  |
| + | n | str | subject |  |
| + | n | str | time |  |
| + | 2 | u16 | body | Corpo do autor. |
| + | 2 | u16 | hue | Cor do autor. |
| + | 1 | u8 | equipCount | Itens equipados. |
| + | 4 | par[] | equip | `itemId` u16 + `hue` u16, repetido `equipCount` vezes. |
| + | 1 | u8 | lineCount | Linhas. |
| + | n | str[] | lines | `lineCount` strings. |

Notas:

Strings: `len` u8 (inclui o terminador) seguido de `len - 1` bytes e um 0x00.
No corpo (subcomando 2) cada linha termina com dois bytes 0x00 e `len` os inclui.
O ClassicUO lê o nome do quadro em 22 bytes; o ServUO escreve 30 bytes.
