# 0xBF / 0x25 - Alternar ícone de feitiço/habilidade
Direção: servidor -> cliente. Tamanho: fixo 8 bytes total.
Finalidade: acende ou apaga o ícone de uma habilidade especial/feitiço.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 8 |
| 3 | 2 | u16 | subcommand | 0x0025 |
| 5 | 2 | u16 | abilityId | Id da habilidade/feitiço |
| 7 | 1 | u8 | active | 1 = ativo, 0 = inativo |
