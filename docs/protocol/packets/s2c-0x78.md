# 0x78 - Mobile Incoming (aparece mobile + equip)

Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload).

Finalidade: Cria um mobile no cliente com seus itens equipados.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x78 |
| 1 | 2 | u16 | length | Tamanho total. |
| 3 | 4 | u32 | serial |  |
| 7 | 2 | u16 | body |  |
| 9 | 2 | u16 | x |  |
| 11 | 2 | u16 | y |  |
| 13 | 1 | i8 | z |  |
| 14 | 1 | u8 | direction |  |
| 15 | 2 | u16 | hue |  |
| 17 | 1 | u8 | flags | Ver 0x77. |
| 18 | 1 | u8 | notoriety |  |
| 19 | n | item[] | equipment | Itens equipados (formato abaixo). |
| fim | 4 | u32 | terminator | 0x00000000. |

**Item equipado (formato novo, 9 bytes)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| +0 | 4 | u32 | serial | Item. |
| +4 | 2 | u16 | graphic | ItemID. |
| +6 | 1 | u8 | layer | Camada. |
| +7 | 2 | u16 | hue | Cor. |

**Item equipado (formato antigo)**

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| +0 | 4 | u32 | serial |  |
| +4 | 2 | u16 | graphic | Bit 15 = hue presente; ItemID = graphic & 0x7FFF. |
| +6 | 1 | u8 | layer |  |
| +7 | 2 | u16 | hue | Somente se graphic & 0x8000. |

Notas:

- Tamanho mínimo: 23 bytes (sem itens).
- Cabelo, barba e rosto são enviados como itens com serial sintético nas camadas Hair, FacialHair e Face.
- Clientes 7.0.33.1+ (`item_hue` sempre presente): cada item tem 9 bytes. Clientes anteriores: `graphic` com bit 0x8000 sinaliza que o `hue` u16 vem a seguir; o item tem 7 ou 9 bytes.
- Exemplo de decisão no ServUO: `NewMobileIncoming` (hue sempre) ou formato antigo (bit 0x8000 em graphic quando hue != 0).
