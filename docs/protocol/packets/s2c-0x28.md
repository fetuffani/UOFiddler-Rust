# 0x28 - Drop Item Failed / Clear Square

Direção: servidor -> cliente. Tamanho: 5 bytes.

Finalidade: Encerra o estado de arrastar item no cliente.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x28 |
| 1 | 4 | u8[4] | payload | Não especificado. |

Notas:

O cliente trata o pacote sem ler nenhum campo (limpa o estado de item segurado). O conteúdo dos 4 bytes não é definido pelas implementações consultadas.

- ClassicUO: `src/ClassicUO.Client/Network/PacketHandlers.cs`: `EndDraggingItem`
- Source-X: `src/network/send.cpp`, `src/network/send.h`: `XCMD_DropRejected` (id declarado em `src/common/sphereproto.h`, sem gerador)
