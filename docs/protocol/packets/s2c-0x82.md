# 0x82 - Login Denied
Direção: servidor -> cliente. Tamanho: 2 bytes.
Finalidade: Rejeita o login da conta com um código de motivo.

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x82 |
| 1 | 1 | u8 | reason | Código do motivo |

Notas: Valores definidos no servidor (`ALRReason`):

| Valor | Nome |
|---|---|
| 0x00 | Invalid |
| 0x01 | InUse (conta em uso) |
| 0x02 | Blocked |
| 0x03 | BadPass |
| 0xFE | Idle |
| 0xFF | BadComm |

O ClassicUO usa o mesmo handler para 0x82, 0x85 e 0x53 e converte o código em mensagem de erro; os textos exatos dependem do cliente.
