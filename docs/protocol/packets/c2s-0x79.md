# 0x79 - ResourceQuery

Direção: cliente -> servidor. Tamanho: 9 bytes (fixo). Disponível: em jogo (somente cliente God).

Finalidade: Consulta de recursos (cliente God).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x79 |
| 1 | 8 | u8[8] | data | Não especificado |

Notas:

O ServUO não lê o conteúdo.
