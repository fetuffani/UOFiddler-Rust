# 0xD7 / 0x13 - Casa: colocar telhado
Direção: cliente -> servidor. Tamanho: fixo 30 bytes total.
Finalidade: adiciona uma peça de telhado (Samurai Empire em diante).

Layout idêntico ao 0x05 (itemId, x, y, z em `enc32`), com `subcommand = 0x0013`.

Notas: o ServUO só aceita de jogadores com `Core.SE`; GMs sempre. O Z deve ser múltiplo de 3 entre -3 e 12, caso contrário vira -3; telhados já existentes na mesma coluna e andar são substituídos.
