# 0x04 - GodModeRequest

Direção: cliente -> servidor. Tamanho: 2 bytes (fixo). Disponível: em jogo (somente cliente God).

Finalidade: Pede para ativar o modo God.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x04 |
| 1 | 1 | u8 | enable | 0 ou 1 |

Notas:

O ServUO desconecta contas sem privilégio de staff. Resposta: 0x2B (2 bytes).

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`GodModeRequest`)
