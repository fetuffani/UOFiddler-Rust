# 0xD7 / 0x06 - Casa: colocar item
Direção: cliente -> servidor. Tamanho: fixo 25 bytes total.
Finalidade: adiciona um componente (parede, piso, porta, etc.) no andar atual.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 25 |
| 3 | 4 | u32 | playerSerial | Jogador |
| 7 | 2 | u16 | subcommand | 0x0006 |
| 9 | 5 | enc32 | itemId | Gráfico do componente |
| 14 | 5 | enc32 | x | Deslocamento X |
| 19 | 5 | enc32 | y | Deslocamento Y |
| 24 | 1 | u8 | terminator | 0x0A |

Notas: o Z não é enviado; o servidor o calcula pelo andar atual (e usa 0 para tiles na borda sul). O ServUO rejeita peças que não são válidas para o nível de expansão (exceto GM) e reenvia o estado.
