# 0x89 - Corpse Clothing
Direção: servidor -> cliente. Tamanho: variável (id + u16 length + payload; length é o tamanho total do pacote).
Finalidade: Lista os itens equipados em um cadáver.

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x89 |
| 1 | 2 | u16 | length | Tamanho total do pacote, incluindo id e este campo |
| 3 | 4 | u32 | serial | Serial do cadáver |
| 7 | 5 x N | entry[] | items | Entradas: u8 layer+1, u32 serial do item |
| fim | 1 | u8 | terminator | 0x00 |

Notas: Entrada: `u8 layerPlus1` (ServUO e ClassicUO: o valor enviado é `layer + 1`; o cliente subtrai 1) seguido de `u32 serial`. O Source-X escreve o valor de layer sem somar 1. A lista termina com um byte 0x00. O ClassicUO ignora a entrada cujo layer (após subtrair 1) é Backpack e ignora o pacote se o objeto não for um cadáver (graphic 0x2006). ServUO também envia cabelo e barba com serials fictícios.
