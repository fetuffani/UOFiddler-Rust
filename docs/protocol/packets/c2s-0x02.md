# 0x02 - Move Request

Direção: cliente -> servidor. Tamanho: 7 bytes (fixo). Disponível: em jogo.

Finalidade: Solicita mover o personagem um passo.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x02 |
| 1 | 1 | u8 | direction | bits 0-2 = direção; bit 0x80 = correndo |
| 2 | 1 | u8 | sequence | número de sequência do passo |
| 3 | 4 | u32 | fastwalkKey | chave de fastwalk; ignorada pelos servidores atuais |

Notas:

Direção (bits 0-2): 0 norte, 1 nordeste (direita), 2 leste, 3 sudeste (baixo), 4 sul, 5 sudoeste (esquerda), 6 oeste, 7 noroeste (cima).

Sequência: o primeiro passo após login, resync ou rejeição usa 0. Após cada passo aceito, o próximo usa sequence + 1; ao chegar em 255 volta para 1 (nunca para 0). Se o servidor não tem sequência ativa (0) e recebe sequence diferente de 0, rejeita.

Resposta: 0x22 Move Acknowledge (3 bytes) em caso de aceitação ou 0x21 Move Reject (8 bytes) em caso de rejeição; após rejeição o servidor zera a sequência e o cliente deve reiniciar com 0 (normalmente após enviar 0x22 Resynchronize).
