# 0x56 - Map Packet (cartography/treasure)

Direção: servidor -> cliente. Tamanho: 11 bytes.

Finalidade: Comandos de edição/exibição de pinos em um mapa.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x56 |
| 1 | 4 | u32 | serial | Item de mapa. |
| 5 | 1 | u8 | command | Comando (tabela). |
| 6 | 1 | u8 | editable | Estado de edição (1 = editável). |
| 7 | 2 | u16 | x | Pixel X do pino. |
| 9 | 2 | u16 | y | Pixel Y do pino. |

Notas:

| command | Significado |
|---|---|
| 1 | Add pin |
| 2 | Insert pin |
| 3 | Move pin |
| 4 | Remove pin |
| 5 | Clear pins (ModernUO usa este valor ao exibir o mapa) |
| 6 | Edit |
| 7 | Edit response (o cliente lê `editable` como estado de plotagem) |

No comando 1 o cliente pula 1 byte (campo `editable`) e lê x e y.
