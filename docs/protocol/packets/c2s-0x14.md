# 0x14 - ChangeZ

Direção: cliente -> servidor. Tamanho: 6 bytes (fixo). Disponível: em jogo (somente cliente God).

Finalidade: Altera a coordenada Z (cliente God).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x14 |
| 1 | 2 | i16 | x | posição X |
| 3 | 2 | i16 | y | posição Y |
| 5 | 1 | i8 | z | novo Z |

Notas:

O ServUO apenas registra o conteúdo.

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`ChangeZ`)
