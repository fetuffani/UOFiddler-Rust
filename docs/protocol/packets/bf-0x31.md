# 0xBF / 0x31 - Temporizador de bandagem
Direção: servidor -> cliente. Tamanho: fixo 15 bytes total.
Finalidade: exibe a contagem regressiva de uso de bandagem.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 15 |
| 3 | 2 | u16 | subcommand | 0x0031 |
| 5 | 2 | u16 | command | 1 |
| 7 | 4 | u32 | icon | 0x00000E21 (gráfico da bandagem) |
| 11 | 4 | u32 | duration | Duração |

Notas: aparece somente no ServUO (`BandageTimerPacket`). A unidade de `duration` não é especificada no código.
