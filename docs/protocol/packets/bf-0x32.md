# 0xBF / 0x32 - Alternar voo (gargoyle)
Direção: cliente -> servidor. Tamanho: fixo 11 bytes total.
Finalidade: pede para alternar o modo de voo do personagem gargoyle.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0032 |
| 5 | 2 | u16 | unknown | 0x0001 (enviado pelo cliente; servidores ignoram) |
| 7 | 4 | u32 | zero | 0 (ignorado) |
