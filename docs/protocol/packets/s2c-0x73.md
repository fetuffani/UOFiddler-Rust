# 0x73 - Ping

Direção: servidor -> cliente. Tamanho: 2 bytes.

Finalidade: Resposta de ping.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x73 |
| 1 | 1 | u8 | value | Valor recebido no ping do cliente, devolvido sem alteração. |
