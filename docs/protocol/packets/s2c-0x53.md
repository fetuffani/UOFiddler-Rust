# 0x53 - Reject Character Logon / Popup message

Direção: servidor -> cliente. Tamanho: 2 bytes.

Finalidade: Exibe uma mensagem de aviso/rejeição ao tentar entrar com um personagem.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x53 |
| 1 | 1 | u8 | code | Código (tabela). |

Notas:

| Valor | Mensagem |
|---|---|
| 0 | Senha incorreta |
| 1 | Personagem não existe |
| 2 | Personagem já existe |
| 3 | Outro |
| 4 | Outro 2 |
| 5 | Personagem já está no mundo |
| 6 | Erro de sincronização |
| 7 | Aviso de inatividade |
| 8 | Não foi possível conectar ao servidor |
| 9 | Transferência de personagem |
| 10 | Nome inválido |

O ServUO define apenas os valores 1, 2, 5, 6 e 7; a lista completa é do Source-X.
