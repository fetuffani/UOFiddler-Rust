# 0xD7 / 0x1A - Casa: reverter
Direção: cliente -> servidor. Tamanho: fixo 10 bytes total.
Finalidade: descarta as alterações e volta ao estado atualmente visível.

Layout idêntico ao 0x02, com `subcommand = 0x001A`.
