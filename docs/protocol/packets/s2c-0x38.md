# 0x38 - Pathfinding

Direção: servidor -> cliente. Tamanho: 7 bytes.

Finalidade: Ordena ao cliente caminhar até uma coordenada.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x38 |
| 1 | 2 | u16 | x |  |
| 3 | 2 | u16 | y |  |
| 5 | 2 | u16 | z |  |
