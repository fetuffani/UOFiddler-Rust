# 0x07 - Pick Up Item

Direção: cliente -> servidor. Tamanho: 7 bytes (fixo). Disponível: em jogo.

Finalidade: Levanta (arrasta) um item ou parte de uma pilha.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x07 |
| 1 | 4 | u32 | serial | serial do item |
| 5 | 2 | u16 | amount | quantidade a levantar |

Notas:

Resposta em caso de recusa: 0x27 Reject Move Item.
