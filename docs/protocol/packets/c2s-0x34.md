# 0x34 - Get Player Status

Direção: cliente -> servidor. Tamanho: 10 bytes (fixo). Disponível: em jogo.

Finalidade: Consulta status ou habilidades de um mobile.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x34 |
| 1 | 4 | u32 | pattern | 0xEDEDEDED |
| 5 | 1 | u8 | type | 0x04 = status; 0x05 = habilidades |
| 6 | 4 | u32 | serial | serial do mobile |

Notas:

Resposta: 0x11 Mobile Status para type 4; 0x3A Skills List para type 5. O tipo 0x00 é enviado pelo cliente God.

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`MobileQuery`)
- Source-X: `src/network/receive.cpp` (`PacketObjStatusReq`)
- ClassicUO: `src/ClassicUO.Client/Network/OutgoingPackets.cs` (`Send_StatusRequest`, `Send_SkillsRequest`)
