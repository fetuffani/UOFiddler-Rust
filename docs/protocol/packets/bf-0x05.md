# 0xBF / 0x05 - Tamanho da tela
Direção: cliente -> servidor. Tamanho: fixo 13 bytes total.
Finalidade: informa a resolução da janela de jogo.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0005 |
| 5 | 4 | u32 | width | Largura em pixels |
| 9 | 4 | u32 | height | Altura em pixels |

Notas: o Source-X trata altura 0 com largura > 0 como "altura omitida" e assume 600 (800), 768 (1024), 864 (1152), 720 (1280) ou 480 (outros). ServUO/ModernUO leem e descartam.
