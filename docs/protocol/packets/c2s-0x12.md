# 0x12 - Use Skill / Cast / Action

Direção: cliente -> servidor. Tamanho: variável (id + u16 length + payload). Disponível: em jogo.

Finalidade: Comando de texto: uso de habilidade, magia, macro e ações do cliente.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x12 |
| 1 | 2 | u16 | length | tamanho total do pacote |
| 3 | 1 | u8 | type | tipo do comando (tabela abaixo) |
| 4 | n | char[] | argument | ASCII terminado por NUL (n = length - 4) |

Notas:

| type | Comando | Argumento |
|---|---|---|
| 0x24 | usar habilidade | "indice 0" (índice da habilidade, espaço, zero) |
| 0x27 | conjurar magia do livro | "idMagia serialLivro" |
| 0x2F | uso de pergaminho antigo (auto-alvo) | "serial", "serial alvo" ou "serial x y z" |
| 0x43 | abrir livro de magias | tipo do livro |
| 0x56 | conjurar magia por macro | número da magia (base 1) |
| 0x58 | abrir porta (macro) | vazio |
| 0xC7 | animação/emote | nome da ação, por exemplo "bow" ou "salute" |
| 0xF4 | invocar virtude (macro) | número da virtude (base 1) |

Para a magia do tipo 0x27 e 0x56 o ServUO subtrai 1 do número recebido. Clientes 6.0.14.2 ou posteriores enviam a conjuração de magia por 0xBF (ver formats-extended-subcommands.md). O Source-X limita o tamanho a 300 + 4 bytes.
