# 0x65 - Set Weather

Direção: servidor -> cliente. Tamanho: 4 bytes.

Finalidade: Define o clima exibido no cliente.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x65 |
| 1 | 1 | u8 | type | Tipo de clima (tabela). |
| 2 | 1 | u8 | count | Intensidade/quantidade de partículas. |
| 3 | 1 | u8 | temperature | Temperatura. |

Notas:

| type | Clima |
|---|---|
| 0 | Chuva |
| 1 | Aproximação de tempestade |
| 2 | Neve |
| 3 | Tempestade se formando |
| 0xFE, 0xFF | Inválido (sem clima) |

O cliente só lê `count` e `temperature` quando o tipo difere do clima atual.
