# 0x55 - Login Complete

Direção: servidor -> cliente. Tamanho: 1 byte.

Finalidade: Indica que o carregamento do mundo terminou.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x55 |

Notas:

Sem campos. O cliente inicia a cena de jogo ao receber.
