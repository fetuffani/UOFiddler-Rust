# 0xD7 / 0x14 - Casa: remover telhado
Direção: cliente -> servidor. Tamanho: fixo 30 bytes total.
Finalidade: remove uma peça de telhado.

Layout idêntico ao 0x05, com `subcommand = 0x0014`. O servidor ignora (e reenvia o estado) se o gráfico não tem a flag Roof.
