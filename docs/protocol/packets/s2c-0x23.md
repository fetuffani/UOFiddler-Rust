# 0x23 - Dragging Item (animação)

Direção: servidor -> cliente. Tamanho: 26 bytes.

Finalidade: Anima um item sendo movido de uma origem para um destino.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x23 |
| 1 | 2 | u16 | graphic | ItemID. |
| 3 | 1 | u8 | graphicOffset | 0; somado ao graphic pelo cliente. |
| 4 | 2 | u16 | hue | Cor. |
| 6 | 2 | u16 | amount | Quantidade. |
| 8 | 4 | u32 | srcSerial | Origem. |
| 12 | 2 | u16 | srcX |  |
| 14 | 2 | u16 | srcY |  |
| 16 | 1 | i8 | srcZ |  |
| 17 | 4 | u32 | dstSerial | Destino. |
| 21 | 2 | u16 | dstX |  |
| 23 | 2 | u16 | dstY |  |
| 25 | 1 | i8 | dstZ |  |

Notas:

Se origem/destino for um mobile conhecido, o cliente usa a posição atual dele em vez dos campos X/Y/Z.
