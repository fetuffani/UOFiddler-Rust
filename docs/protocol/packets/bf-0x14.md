# 0xBF / 0x14 - Exibir menu de contexto
Direção: servidor -> cliente. Tamanho: variável (`12 + soma das entradas`).
Finalidade: envia as entradas do menu de contexto.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | Tamanho total |
| 3 | 2 | u16 | subcommand | 0x0014 |
| 5 | 2 | u16 | mode | 1 = entradas no formato antigo; 2 (ou maior) = formato novo |
| 7 | 4 | u32 | serial | Alvo do menu |
| 11 | 1 | u8 | count | Número de entradas |
| 12 | ... | entry[count] | entries | Ver abaixo |

Entrada no formato novo (`mode >= 2`), 8 bytes:

| Campo | Tipo | Descrição |
|---|---|---|
| cliloc | u32 | Cliloc completo do texto (ServUO soma 3000000 se o número é <= 65535 no formato "Old" com cor) |
| index | u16 | Índice devolvido no 0x15 |
| flags | u16 | Tabela de flags |

Entrada no formato antigo (`mode = 1`), 6 bytes mais 2 opcionais:

| Campo | Tipo | Descrição |
|---|---|---|
| index | u16 | Índice devolvido no 0x15 |
| cliloc - 3000000 | u16 | Cliloc de 3000000 + valor |
| flags | u16 | Tabela de flags |
| color | u16 | Presente somente se `flags & 0x20` (cor do texto) |

Flags (`CMEFlags`):

| Valor | Nome | Significado |
|---|---|---|
| 0x0000 | None | Habilitada |
| 0x0001 | Disabled | Entrada desabilitada (o cliente desenha em cinza) |
| 0x0002 | Arrow | Entrada com seta (submenu) |
| 0x0004 | Highlighted | Destacada |
| 0x0020 | Colored | Para o formato antigo, um `u16 color` segue os flags |

Notas:
- No ModernUO, `mode = 2` só é usado para cliente New Haven/EC com entrada que exige o formato novo; caso contrário envia `mode = 1`.
- No formato antigo o ClassicUO também consome 2 bytes extras quando os flags `0x84` ou `0x40` estão ativos; os servidores consultados não emitem esses flags.
- O índice devolvido no 0x15 é a posição da entrada na lista (0 a count-1).
