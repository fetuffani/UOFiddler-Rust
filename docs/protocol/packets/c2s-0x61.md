# 0x61 - DeleteStatic

Direção: cliente -> servidor. Tamanho: 9 bytes (fixo). Disponível: em jogo (somente cliente God).

Finalidade: Remove um estático (cliente God).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x61 |
| 1 | 2 | i16 | x | X |
| 3 | 2 | i16 | y | Y |
| 5 | 2 | i16 | z | Z |
| 7 | 2 | u16 | graphic | id do estático |

Notas:

O ServUO apenas registra o conteúdo.
