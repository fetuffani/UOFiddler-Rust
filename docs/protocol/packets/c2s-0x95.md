# 0x95 - HuePickerResponse

Direção: cliente -> servidor. Tamanho: 9 bytes (fixo). Disponível: em jogo.

Finalidade: Resposta ao seletor de cor (0x95 do servidor).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x95 |
| 1 | 4 | u32 | serial | serial do seletor/objeto |
| 5 | 2 | u16 | itemId | o cliente de referência envia 0 |
| 7 | 2 | u16 | hue | cor escolhida (14 bits utilizados, máscara 0x3FFF) |
