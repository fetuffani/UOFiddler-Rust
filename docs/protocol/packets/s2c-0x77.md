# 0x77 - Update Mobile (move/animação de outro)

Direção: servidor -> cliente. Tamanho: 17 bytes.

Finalidade: Atualiza posição, direção, cor e flags de outro mobile.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x77 |
| 1 | 4 | u32 | serial |  |
| 5 | 2 | u16 | body |  |
| 7 | 2 | u16 | x |  |
| 9 | 2 | u16 | y |  |
| 11 | 1 | i8 | z |  |
| 12 | 1 | u8 | direction |  |
| 13 | 2 | u16 | hue |  |
| 14 | 1 | u8 | flags | Ver tabela. |
| 15 | 1 | u8 | notoriety | Notoriedade. |

Notas:

Flags de mobile (`flags`):

| Bit | Significado |
|---|---|
| 0x01 | Congelado/paralisado |
| 0x02 | Feminino |
| 0x04 | Envenenado (antes do cliente 7.0.0.0) ou voando (depois) |
| 0x08 | Barra de vida amarela |
| 0x10 | Ignora mobiles |
| 0x40 | Modo de guerra |
| 0x80 | Oculto |

Notoriedade: 1 inocente, 2 aliado, 3 cinza, 4 criminoso, 5 inimigo, 6 assassino, 7 invulnerável.
Para o próprio jogador o cliente só atualiza flags, corpo, cor e notoriedade.
