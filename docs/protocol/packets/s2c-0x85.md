# 0x85 - Character Delete Result
Direção: servidor -> cliente. Tamanho: 2 bytes.
Finalidade: Informa o resultado de um pedido de exclusão de personagem.

Convenções: offsets contados a partir do primeiro byte do pacote (o id); inteiros de mais de um byte em big-endian; u8/u16/u32 sem sinal, i8/i16/i32 com sinal.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x85 |
| 1 | 1 | u8 | result | Código do resultado |

Notas: Valores (`DeleteResultType`): 0 PasswordInvalid, 1 CharNotExist, 2 CharBeingPlayed, 3 CharTooYoung, 4 CharQueued, 5 BadRequest. Em caso de sucesso o servidor envia em seguida o 0x86 com a lista atualizada.
