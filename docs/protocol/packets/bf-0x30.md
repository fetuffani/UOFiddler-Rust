# 0xBF / 0x30 - Alvo por recurso (macro)
Direção: cliente -> servidor. Tamanho: fixo 11 bytes total.
Finalidade: aplica uma ferramenta a um tipo de recurso escolhido.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 11 |
| 3 | 2 | u16 | subcommand | 0x0030 |
| 5 | 4 | u32 | serial | Item (ferramenta); ignorado se não for item |
| 9 | 2 | u16 | resourceType | Tipo de recurso |
