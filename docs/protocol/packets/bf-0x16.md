# 0xBF / 0x16 - Fechar janela de interface
Direção: servidor -> cliente. Tamanho: fixo 13 bytes total.
Finalidade: fecha uma janela de interface do cliente (paperdoll, status, perfil, container).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 13 |
| 3 | 2 | u16 | subcommand | 0x0016 |
| 5 | 4 | u32 | windowType | Tabela abaixo |
| 9 | 4 | u32 | serial | Serial do dono da janela |

| windowType | Janela |
|---|---|
| 1 | Paperdoll |
| 2 | Barra/janela de status |
| 8 | Perfil de personagem |
| 0x0C | Container |
