# 0xD7 / 0x02 - Casa: backup
Direção: cliente -> servidor. Tamanho: fixo 10 bytes total.
Finalidade: salva uma cópia do design atual para uso posterior (restore).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 10 |
| 3 | 4 | u32 | playerSerial | Jogador |
| 7 | 2 | u16 | subcommand | 0x0002 |
| 9 | 1 | u8 | terminator | 0x0A |
