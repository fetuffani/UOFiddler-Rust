# 0xD7 / 0x12 - Casa: trocar de andar
Direção: cliente -> servidor. Tamanho: fixo 15 bytes total.
Finalidade: muda o andar de edição.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xD7 |
| 1 | 2 | u16 | length | 15 |
| 3 | 4 | u32 | playerSerial | Jogador |
| 7 | 2 | u16 | subcommand | 0x0012 |
| 9 | 5 | enc32 | level | Andar de destino (1 a MaxLevels) |
| 14 | 1 | u8 | terminator | 0x0A |

Notas: valores fora do intervalo viram 1 no ServUO; o servidor teleporta o jogador para o novo andar.
