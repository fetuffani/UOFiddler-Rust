# 0xBF / 0x02 - Fastwalk: adicionar chave
Direção: servidor -> cliente. Tamanho: fixo 9 bytes total.
Finalidade: empilha uma nova chave de fast walk.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 9 |
| 3 | 2 | u16 | subcommand | 0x0002 |
| 5 | 4 | u32 | key | Chave a adicionar |
