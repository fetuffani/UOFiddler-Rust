# 0xBF / 0x18 - Habilitar map patches
Direção: servidor -> cliente. Tamanho: variável (`9 + 8 * mapCount`).
Finalidade: informa a quantidade de blocos nos arquivos de diff de cada mapa.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | Tamanho total (41 para 4 mapas) |
| 3 | 2 | u16 | subcommand | 0x0018 |
| 5 | 4 | u32 | mapCount | Número de mapas descritos |
| 9 | 8 | par[mapCount] | patches | Por mapa: `u32 staticBlocks` + `u32 landBlocks` |

Notas:
- ServUO, ModernUO e ClassicUO usam a ordem "estáticos, depois terreno". O Source-X escreve o comprimento do arquivo de diff de terreno primeiro e o de estáticos depois (ordem inversa); isso é uma divergência não resolvida entre implementações.
- Cada contagem é o tamanho do arquivo de índice de diff (`*difl`) dividido por 4.
