# 0x20 - Draw Game Player (posição/direção própria)

Direção: servidor -> cliente. Tamanho: 19 bytes.

Finalidade: Atualiza corpo, cor, flags, posição e direção do personagem do jogador.

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x20 |
| 1 | 4 | u32 | serial | Jogador. |
| 5 | 2 | u16 | body | Corpo. |
| 7 | 1 | u8 | bodyOffset | 0 (incremento do corpo). |
| 8 | 2 | u16 | hue | Cor. |
| 10 | 1 | u8 | flags | Ver tabela. |
| 11 | 2 | u16 | x | X. |
| 13 | 2 | u16 | y | Y. |
| 15 | 2 | u16 | serverId | 0 em ServUO/ModernUO. |
| 17 | 1 | u8 | direction | Direção. |
| 18 | 1 | i8 | z | Z. |

Notas:

Flags de mobile (`flags`):

| Bit | Significado |
|---|---|
| 0x01 | Congelado/paralisado |
| 0x02 | Feminino |
| 0x04 | Envenenado (antes do cliente 7.0.0.0) ou voando (depois) |
| 0x08 | Barra de vida amarela (abençoado/invulnerável) |
| 0x10 | Ignora mobiles |
| 0x20 | Movível |
| 0x40 | Modo de guerra |
| 0x80 | Oculto |

Os servidores antes do cliente 7.0.0.0 enviam o bit 0x04 como veneno (`GetOldPacketFlags`).
