# 0x75 - RenameRequest

Direção: cliente -> servidor. Tamanho: 35 bytes (fixo). Disponível: em jogo.

Finalidade: Renomeia um mobile (por exemplo animal de estimação).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0x75 |
| 1 | 4 | u32 | serial | serial do mobile |
| 5 | 30 | char[30] | name | novo nome, ASCII com preenchimento NUL |

Referência de implementação:

- ServUO: `Server/Network/PacketHandlers.cs` (`RenameRequest`)
- ModernUO: `Projects/UOContent/Network/Packets/IncomingMobilePackets.cs` (`RenameRequest`)
- Source-X: `src/network/receive.cpp` (`PacketCharRename`)
