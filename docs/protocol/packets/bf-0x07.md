# 0xBF / 0x07 - Clique na seta de quest
Direção: cliente -> servidor. Tamanho: fixo 6 bytes total.
Finalidade: o jogador clicou na seta de quest (apontador).

| Offset | Tamanho | Tipo | Campo | Descrição |
|---|---|---|---|---|
| 0 | 1 | u8 | id | 0xBF |
| 1 | 2 | u16 | length | 6 |
| 3 | 2 | u16 | subcommand | 0x0007 |
| 5 | 1 | u8 | rightClick | 1 = botão direito, 0 = esquerdo |
